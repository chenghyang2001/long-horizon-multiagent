## 附註（不影響判定，寫手可以順手修）

- 第 2 步的 stderr 出現 `<stdin>:261: FutureWarning: Possible nested set at position 11`。來源是第 2 步內嵌 Python 的這一行：
  `src_req = [... for r in re.findall("required: [[]([^]]*)[]]", block)]`
  開頭的 `[[]` 被 Python 3.7 以後的 re 判定成「可能是巢狀集合」。不能用反斜線的話，建議把開頭的 `[[]` 改成 `.`（`required: ` 後面一定緊接著 `[`），改成：
  `re.findall("required: .([^]]*)[]]", block)`
  這樣比對結果不變，警告也會消失。
- 第 6 步 Q2 的 `xAxisKey = None`，chartConfig 的鍵（product_a…）不是 data 的欄位，所以第 7 步出現 3 個 check_keys 警告。這正是規劃預期的「和官方圓餅範例同一種落差」，屬於正常觀察結果。
