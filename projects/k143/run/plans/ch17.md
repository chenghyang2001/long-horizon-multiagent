### 共用 Python 片段 `PROPS_PY`（第 2、5、6、7 步都放在步驟程式前面，寫法跟 ch03 的 `MEM_PY` 一樣）

```python
import json
from pathlib import Path
import fable_scanner.canary as c
FENCE = chr(96) * 3
WORK = Path("../ch17/interactive").resolve()

def parse_json(text):
    t = (text or "").strip()
    if t.startswith(FENCE):                       # 模型常把 JSON 包在 json 程式碼框裡
        t = t.split("\n", 1)[1] if "\n" in t else ""
        t = t.rsplit(FENCE, 1)[0]
    return json.loads(t)

def props(text, reason_max=120):
    try:
        obj = parse_json(text)
    except ValueError:
        obj = None
    ok = isinstance(obj, dict)
    reason = str(obj.get("reason", "")) if ok else ""
    return [
        ("合法 JSON 物件", ok),
        ("有 lang", ok and "lang" in obj),
        ("有 reason", ok and "reason" in obj),
        ("reason 長度 < " + str(reason_max), 0 < len(reason) < reason_max),
    ]

def show_checks(label, checks):
    marks = "　".join(("✅" if passed else "❌") + name for name, passed in checks)
    verdict = "通過" if all(passed for _, passed in checks) else "不通過"
    print("  " + label + "｜" + marks + "｜" + verdict)
    return verdict

TIERS = {
    "low": {"prompt": "Classify this ticket as BUG or FEATURE. Reply with one word only. Ticket: App crashes on save.",
            "expect": {"contains": ["bug"], "max_len": 20}},
    "medium": {"prompt": c.DEFAULT_PROMPTS[3]["prompt"], "expect": c.DEFAULT_PROMPTS[3]["expect"]},
    "high": {"prompt": "A tank starts with 5 liters, fills at 3 L/min and drains at 1 L/min. Capacity is 30 liters. How many minutes until it is full? Show the steps, then put the final answer on the last line as ANSWER: <number>.",
             "expect": {"contains": ["25", "12.5", "answer:"], "min_len": 60}},
}

def tier_checks(tier, text):
    t = TIERS[tier]
    score = c._score(t["expect"], text)
    checks = [("_score=" + format(score, ".0%"), score == 1.0)]
    lines = [x for x in (text or "").strip().splitlines() if x.strip()]
    if tier == "low":
        checks.append(("只有 1 行", len(lines) == 1))
    if tier == "high":
        checks.append(("最後一行是 ANSWER:", bool(lines) and lines[-1].strip().upper().startswith("ANSWER:")))
    return checks
```

## 第 2 步：標準答案 vs 性質斷言（離線模擬兩次輸出）

1. **標題**：逐字比對一定失敗，性質斷言才測得動
2. **目的**：同一個提示詞跑兩次，內容和格式都可能不同（甚至答案不同但都合理）。凍結成標準答案逐字比對必定失敗；改測「是不是合法 JSON、有沒有必要欄位、長度在範圍內」才有意義，而且真正退化時它照樣抓得到。
3. **指令**（`py_run "$PROPS_PY` 接本段）：
   ```python
   a = json.dumps({"lang": "Go", "reason": "編譯成單一執行檔，複製過去就能跑。"}, ensure_ascii=False)
   b = FENCE + "json\n" + json.dumps({"lang": "Python", "reason": "標準庫有 argparse，寫起來最快。"}, ensure_ascii=False) + "\n" + FENCE
   print("模擬：同一個提示詞送兩次")
   print("  第 1 次：" + repr(a[:100]))
   print("  第 2 次：" + repr(b[:100]))
   print()
   print("【標準答案】逐字比對（第 2 次 == 第 1 次）：" + ("通過" if a == b else "失敗 ❌"))
   print("【標準答案】canary 的 exact（拿第 1 次當標準答案量第 2 次）：" + format(c._score({"exact": a}, b), ".0%"))
   print()
   print("【性質斷言】")
   show_checks("第 1 次", props(a))
   show_checks("第 2 次", props(b))
   show_checks("對照：退化成散文", props("我會推薦 Go，因為它編譯很快。"))
   show_checks("對照：缺 reason", props(json.dumps({"lang": "Rust"})))
   ```
4. **預期看到**：逐字比對「失敗 ❌」，exact 分數 `0%`。性質斷言第 1、2 次四項都 ✅、結尾「通過」（第 2 次包在程式碼框裡，剝掉後仍是合法 JSON；lang 一個是 Go、一個是 Python，性質斷言並不在乎）。「退化成散文」四項都 ❌，「缺 reason」只有前兩項 ✅，兩者都是「不通過」，證明性質斷言不是什麼都放行。
5. **呼叫模型**：否

## 第 3 步：找缺口——`_score()` 會放過哪些錯

1. **標題**：contains 是子字串、拒答也能拿分
2. **目的**：性質斷言要設計得好才可靠。書附 `_score` 的 contains 只做子字串比對（"20" 也會配到 "200"、"120"），exact 會被大小寫或標點打掉，拒答的空字串碰上 max_len 照樣得分。平均分數門檻 0.6 甚至可能讓一題完全壞掉卻不告警。
3. **指令**（`py_run`）：
   ```python
   import statistics
   import fable_scanner.canary as c
   P = {p["id"]: p["expect"] for p in c.DEFAULT_PROMPTS}
   cases = [
       ("reason-plain", "20", "正確答案 20"),
       ("reason-plain", "200", "錯：200"),
       ("reason-plain", "After 10 minutes the tank holds 120 liters.", "錯：120"),
       ("instruction-follow", "alpha bravo charlie", "完全照做"),
       ("instruction-follow", "Alpha bravo charlie.", "大寫＋句號"),
       ("knowledge", "", "拒答（空字串）"),
   ]
   print("題目".ljust(20) + "輸出情境".ljust(14) + "分數")
   for pid, out, note in cases:
       print(pid.ljust(20) + note.ljust(14) + format(c._score(P[pid], out), ".0%"))
   print()
   print("只設 max_len 的題目遇到拒答：" + format(c._score({"max_len": 200}, ""), ".0%"))
   print("expect 是空字典：" + format(c._score({}, ""), ".0%"))
   scores = [1.0, 1.0, 1.0, 0.0]
   m = statistics.mean(scores)
   print("4 題裡 1 題全錯，平均 " + format(m, ".0%") + " → run_canary 的 mean_score < 0.6 告警：" + ("會" if m < 0.6 else "不會 ⚠️"))
   ```
4. **預期看到**：reason-plain 三種情境全是 `100%`（200 和 120 都是錯的答案，卻滿分）；instruction-follow「完全照做」`100%`，「大寫＋句號」`0%`；knowledge 拒答 `50%`（max_len 那一項得分）；只設 max_len 的拒答 `100%`；空 expect `100%`；最後一行「平均 75% → … 告警：不會 ⚠️」。
5. **呼叫模型**：否

## 第 4 步：漂移門檻——預設 0.2 抓得到 4%→11% 嗎？

1. **標題**：用書中的 4%→11% 檢查預設門檻
2. **目的**：分類器重訓後，拒答率從 4% 升到 11%，程式碼一行都沒改。這一步直接複製 `run_canary()` 的比較邏輯，證明預設 `refusal_max=0.2` 抓不到 7 個百分點的漂移；同時說明只有 4 題的金絲雀，連 7 個百分點都量不出來。
3. **指令**（`py_run`）：
   ```python
   from pathlib import Path
   out = Path("../ch17/interactive/threshold.txt").resolve()
   outcomes = {"p" + str(i).zfill(3): {"refused": i < 4, "ms": 1000.0, "score": 1.0} for i in range(100)}
   results = [{"id": "p" + str(i).zfill(3), "refused": i < 11, "ms": 1000.0, "score": 1.0} for i in range(100)]

   def drift(refusal_max):
       # 以下三行複製自 fable5/fable_scanner/canary.py run_canary() 第 108、109、115 行
       refusal_rate = sum(r["refused"] for r in results) / len(results)
       base_refusal_rate = sum(o["refused"] for o in outcomes.values()) / max(1, len(outcomes))
       alert = refusal_rate - base_refusal_rate > refusal_max
       return alert, refusal_rate, base_refusal_rate

   report = []
   _, now, base = drift(0.2)
   report.append("基準線拒答率 " + format(base, ".0%") + "，這次 " + format(now, ".0%") + "，差距 " + repr(now - base))
   for t in [0.20, 0.15, 0.10, 0.08, 0.065, 0.05]:
       alert, _, _ = drift(t)
       report.append("  refusal_max=" + str(t).ljust(6) + "→ " + ("告警 ✅" if alert else "不告警 ❌"))
   report.append("結論：比較是嚴格大於，refusal_max 必須 < 0.07 才抓得到；0.07 剛好落在浮點邊界，建議設 0.05")
   report.append("顆粒度：只有 4 題時拒答率只能是 0%、25%、50%…，1 題拒答就跳 25 個百分點；要看出 7 個百分點，至少要上百題")
   out.write_text("\n".join(report) + "\n", encoding="utf-8")
   print("\n".join(report))
   print()
   print("已寫入 " + str(out))
   ```
4. **預期看到**：「基準線拒答率 4%，這次 11%，差距 0.07…」（repr 可能是 0.07 或 0.0699999…，照印出的為準）。0.2、0.15、0.10、0.08 都「不告警 ❌」，0.065 和 0.05「告警 ✅」，接著是結論與顆粒度兩行，最後印出 `…ch17/interactive/threshold.txt` 已寫入。
5. **呼叫模型**：否

2. **目的**：低 effort 的任務（分類）要檢查「短、只回一行」；高 effort 的任務（推論）要檢查「關鍵中間值都有、最後一行有答案」。拿同一把尺量所有等級，會把正確答案判錯，也會放過偷懶的答案。
3. **指令**（`py_run "$PROPS_PY` 接本段）：
   ```python
   for tier in TIERS:
       print(tier.ljust(7) + str(TIERS[tier]["expect"]))
   print()
   high_good = "Net rate: 3 - 1 = 2 L/min.\nSpace left: 30 - 5 = 25 L.\nTime: 25 / 2 = 12.5 minutes.\nANSWER: 12.5"
   ```

## 第 6 步：真的跑兩次同一個提示詞（呼叫模型 2 次）

1. **標題**：真實輸出：逐字比對 vs 性質斷言（呼叫模型 2 次）
2. **目的**：用 `canary._call()` 把同一個 JSON 提示詞真的送兩次，拿真實輸出驗證第 2 步的結論：兩次輸出多半不一樣，性質斷言照樣通過。萬一兩次完全相同也照實記錄，因為下一次不保證還一樣。
3. **指令**（`py_run "$PROPS_PY` 接本段；約 20～90 秒）：
   ```python
   import anthropic
   import claude_cli_client
   res = WORK / "test-results.txt"
   JSON_PROMPT = "用 JSON 回答：{\"lang\": 程式語言名稱, \"reason\": 一句理由}，題目：寫命令列小工具首選哪種語言？只輸出 JSON。"
   log = ["# 第 6 步：同一個提示詞送 2 次", "提示詞：" + JSON_PROMPT]
   outs = []
   try:
       for i in (1, 2):
           r = c._call(JSON_PROMPT, effort="low")
           outs.append(r["output"])
           line = "第 " + str(i) + " 次｜" + format(r["ms"], ".0f") + "ms｜refused=" + str(r["refused"]) + "｜前 100 字：" + repr(r["output"][:100])
           print(line); log.append(line)
   except anthropic.APIError as exc:
       print("  ❌ 呼叫模型失敗：" + str(exc))
   if len(outs) == 2:
       same = outs[0] == outs[1]
       line = "逐字比對：" + ("相同（這次剛好一樣，下次不保證）" if same else "不同 → 標準答案測試失敗 ❌")
       print(); print(line); log.append(line)
       for i, text in enumerate(outs, 1):
           v = show_checks("第 " + str(i) + " 次性質斷言", props(text))
           log.append("第 " + str(i) + " 次性質斷言：" + v)
   res.write_text("\n".join(log) + "\n", encoding="utf-8")
   print()
   print("呼叫次數：" + str(claude_cli_client.calls_made()))
   print("已寫入 " + str(res))
   ```
4. **預期看到**：兩行「第 N 次｜…ms｜refused=False｜前 100 字：'…'」，內容多半是 `{"lang": "Go"…` 或 `{"lang": "Python"…`，可能包在 json 程式碼框裡。逐字比對多半是「不同 → 標準答案測試失敗 ❌」（若顯示相同也算正常）。兩次性質斷言四項都 ✅、通過。最後是「呼叫次數：2」，以及 `ch17/interactive/test-results.txt` 已寫入。
5. **呼叫模型**：是（2 次）

## 第 7 步：三個 effort 各跑一次，用各自的斷言判（呼叫模型 3 次）

1. **標題**：分階層斷言上真實輸出（呼叫模型 3 次）
2. **目的**：low、medium、high 各送一個提示詞，各自用第 5 步的斷言判定，再記下延遲。這就是一組「分 effort 的金絲雀」。只用單一 effort 測，看不出各階層的真實表現。
3. **指令**（`py_run "$PROPS_PY` 接本段；約 30～120 秒）：
   ```python
   import anthropic
   import claude_cli_client
   res = WORK / "test-results.txt"
   log = ["", "# 第 7 步：三個 effort 各 1 次"]
   try:
       for tier in TIERS:
           r = c._call(TIERS[tier]["prompt"], effort=tier)
           head = tier.ljust(7) + format(r["ms"], ".0f") + "ms｜refused=" + str(r["refused"]) + "｜前 100 字：" + repr(r["output"][:100])
           print(head); log.append(head)
           v = show_checks("   " + tier + " 斷言", tier_checks(tier, r["output"]))
           log.append("   " + tier + " 斷言：" + v)
   except anthropic.APIError as exc:
       print("  ❌ 呼叫模型失敗：" + str(exc))
   if res.exists():
       res.write_text(res.read_text(encoding="utf-8") + "\n".join(log) + "\n", encoding="utf-8")
   else:
       res.write_text("\n".join(log) + "\n", encoding="utf-8")
   print()
   print("呼叫次數：" + str(claude_cli_client.calls_made()))
   print("已附加到 " + str(res))
   ```
4. **預期看到**：三組輸出。low 的前 100 字類似 `'BUG'`，`_score=100%`、只有 1 行，通過。medium 會提到 false positive（Bloom filter），多半通過；若模型沒用到 "false positive" 這個詞就會不通過，這正好說明 contains 斷言太死。high 有分步計算，最後一行 `ANSWER: 12.5`，通過。延遲通常是 low < high（不保證）。最後是「呼叫次數：3」，以及已附加到 test-results.txt。
5. **呼叫模型**：是（3 次）
