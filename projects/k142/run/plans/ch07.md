> 主角：`harnesslab.core` 的 `Tracer`、`TraceSpan`、`EvidenceEnvelope`（`tamper_evident_hash()`），以及 `chapters/ch07/scenario.py` 的 `_redact_payload`、`_regression_report`、`_metric_score`、`_stable_hash`。
> 執行方式（照 ch02.sh 的 `run()`）：`cd practice/HarnessLab && PYTHONUTF8=1 PYTHONPATH=. python -`，把內嵌 Python 從 stdin 餵進去。

> 對應練習：練習 1（拆開證據信封與回歸閘門）→ 第 5、7 步；練習 2（真實模型呼叫封進信封＋竄改）→ 第 1～4、6 步。

## 已讀原始碼確認的名稱（供實作者核對）

- `harnesslab/core.py`
  - `TraceSpan(span_id, name, started_at, ended_at=None, attributes={}, events=[])`，方法 `finish()`。
  - `EvidenceEnvelope(run_id, actor, policy_version, spans, artifact_hashes, redactions, created_at)`，方法 `tamper_evident_hash()`：把 run_id、actor、policy_version、`[span.__dict__ ...]`、artifact_hashes、redactions、created_at 用 `json.dumps(sort_keys=True)` 再 sha256。
  - `Tracer(run_id, actor, policy_version="training-policy-v1")`：`span(name, **attributes)`（context manager，yield `TraceSpan`，span_id = `stable_id("span", run_id, name, 序號)`，結束時 `finish()`）、`event(span, name, **attributes)`、`envelope(artifacts=None, redactions=None)`（`created_at=time.time()`，`spans` 直接引用 `tracer.spans` 同一份物件）。
  - `stable_id(prefix, *parts)` → `f"{prefix}_{sha256前16碼}"`。
- `chapters/ch07/scenario.py`
  - `EMAIL_PATTERN`、`TOKEN_PATTERN = r"\b(token=|sk_live_)[A-Za-z0-9_.:=/-]+\b"`、`SENSITIVE_KEYS = {"customer_email","api_token","secret","password"}`。
  - `_redact_payload(payload) -> (遮蔽後, redactions)`，標記格式 `field:<key>`、`pattern:email`、`pattern:token`；替換字串 `[REDACTED_EMAIL]`、`[REDACTED_SECRET]`、`[REDACTED_TOKEN]`。
  - `_regression_report(baseline, candidate)` → 鍵 `baseline`、`candidate`、`deltas`、`failed_gates`、`verdict`（`"escalate"`／`"pass"`）；安全指標 `unsafe_block_rate`、`redaction_recall`、`replay_pass_rate`。
  - `_metric_score(metrics)`：0.35×task_success＋0.30×unsafe_block_rate＋0.20×redaction_recall＋0.15×replay_pass_rate－max(latency−900,0)/10000，取 4 位。
  - `_stable_hash(payload)`：`json.dumps(sort_keys=True, separators=(",",":"), default=str)` 的 sha256。
- `python -m harnesslab.cli run ch07 --json` 印出的是 **list**（`[result.to_dict()]`），所以要 `data[0]["artifacts"]`。
  - artifacts 鍵：`redacted_observation`、`decision_trace`、`trace_spans`、`benchmark_regression`、`hill_climb`、`governed_rsi`、`replay_bundle`、`artifact_hashes`、`evidence_envelope`（含 `run_id`、`actor`、`policy_version`、`redactions`、`artifact_hashes`、`tamper_evident_hash`）、`replay_verified`。
  - `hill_climb` 鍵：`baseline`、`iterations`（每輪 `iteration`、`candidate`、`change`、`metrics`、`score`、`regression_gates`、`accepted`）、`selected`（`candidate`、`metrics`、`score`）。
  - `governed_rsi` 鍵：`denied_attempt`（`status`、`missing_controls`…）、`approved_attempt`（`status`、`evidence_hash`、`rollback_checkpoint`、`required_controls`…）。
  - `replay_bundle` 鍵：`schema`、`run_id`、`policy_version`、`inputs`（`raw_observation_hash`、`redacted_observation`）、`trace`、`expected_decision_trace`、`expected_regression_verdict`、`expected_selected_candidate`。
- `practice/llm_agent.py`：`ask(prompt) -> str`、`ask_json(prompt) -> dict`；從 HarnessLab 匯入要先 `sys.path.insert(0, "..")`（同 ch06.sh）。

## 第 1 步：開一條決策軌跡，封進證據信封

1. **標題**：認識主角：Tracer、TraceSpan 和 EvidenceEnvelope
2. **目的**：可觀測性的基本單位是「span」（一段決策紀錄），所有 span 加上產物雜湊、遮蔽紀錄、政策版本，會被封成一個證據信封，最後壓成一個防竄改雜湊。
3. **指令（內嵌 Python）**：
```python
from harnesslab.core import Tracer
tracer = Tracer(run_id="k142-ch07", actor="triage-subagent")
with tracer.span("subagent_call", tool="ask", data_class="internal") as span:
    tracer.event(span, "policy.decision", decision="allow", reason="唯讀摘要任務")
    span.attributes["note"] = "這裡之後會放遮蔽後的 prompt 與回覆"
env = tracer.envelope(artifacts={"reply_sha256": "尚未呼叫模型"}, redactions=[])
print("run_id      ：", env.run_id)
print("actor       ：", env.actor)
print("政策版本    ：", env.policy_version)
s = env.spans[0]
print("span_id     ：", s.span_id)
print("span 名稱   ：", s.name)
print("屬性        ：", s.attributes)
print("事件        ：", [e["name"] for e in s.events])
print("有結束時間  ：", s.ended_at is not None)
print("防竄改雜湊  ：", env.tamper_evident_hash())
```
4. **預期看到**：
   - `run_id` 為 `k142-ch07`、`actor` 為 `triage-subagent`、政策版本為預設的 `training-policy-v1`。
   - `span_id` 形如 `span_` 加 16 位十六進位（同一個 run_id／名稱／序號每次都一樣）。
   - 屬性含 `tool`、`data_class`、`note`；事件清單為 `['policy.decision']`；`有結束時間  ： True`。
   - 防竄改雜湊是 64 位十六進位；**每次執行都不同**，因為 span 的時間戳與信封的 `created_at` 都是 `time.time()`（tip 可提醒：書附情境用固定時間 `FIXED_TIME` 才能重播出同一個雜湊）。
5. **是否呼叫模型**：否

## 第 2 步：寫進軌跡前先遮蔽

1. **標題**：書附遮蔽器：敏感欄位和字串樣式各抓一次
2. **目的**：敏感資料要在「寫進軌跡之前」就換掉，並把遮蔽了哪些東西記下來；書附遮蔽器同時看欄位名（`customer_email`）與字串樣式（email、`token=`、`sk_live_`）。
3. **指令（內嵌 Python）**：
```python
from chapters.ch07.scenario import _redact_payload, SENSITIVE_KEYS
raw = {
    "ticket_id": "INC-407",
    "customer_email": "alex.customer@example.com",
    "draft": "結案通知。請聯絡 ops@example.com，Never log token=sk_live_training_secret.",
    "password": "hunter2",
}
red, marks = _redact_payload(raw)
print("書附敏感欄位名：", sorted(SENSITIVE_KEYS))
for k in raw:
    print(f"  {k:<15} 原={raw[k]!r}\n  {'':<15} 後={red[k]!r}")
print("遮蔽紀錄：", marks)
```
4. **預期看到**：
   - `customer_email` → `'[REDACTED_EMAIL]'`；`password` → `'[REDACTED_SECRET]'`（欄位名命中）。
   - `draft` 變成 `'結案通知。請聯絡 [REDACTED_EMAIL]，Never log [REDACTED_TOKEN].'`（樣式命中）。
   - `ticket_id` 原樣保留（調查仍需要它）。
   - 遮蔽紀錄：`['field:customer_email', 'pattern:email', 'pattern:token', 'field:password']`（順序依欄位走訪順序）。
5. **是否呼叫模型**：否

## 第 3 步：陷阱：遮蔽規則沒寫到的，就漏網

1. **標題**：陷阱：`api_key=` 不在書附規則裡
2. **目的**：遮蔽是「列舉出來的才會擋」。練習 2 的假資料 `api_key=sk-test-123` 不符合 `token=`／`sk_live_` 樣式，書附遮蔽器會放過它；要自己補一條規則，並把補的規則也記進 redactions。
3. **指令（內嵌 Python）**：
```python
import re
from chapters.ch07.scenario import _redact_payload, TOKEN_PATTERN
text = "客戶 email: amy@example.com，api_key=sk-test-123，請分流。"
book, book_marks = _redact_payload(text)
print("書附 TOKEN 規則：", TOKEN_PATTERN.pattern)
print("書附遮蔽後：", book)
print("書附紀錄  ：", book_marks)
print("金鑰漏網？：", "sk-test-123" in book)

API_KEY = re.compile(r"api_key\s*[=:]\s*[A-Za-z0-9_\-]+", re.I)
def redact_text(t):
    out, marks = _redact_payload(t)
    new = API_KEY.sub("api_key=[REDACTED_SECRET]", out)
    if new != out:
        marks.append("pattern:api_key")
    return new, marks
fixed, fixed_marks = redact_text(text)
print("\n補規則後  ：", fixed)
print("補後紀錄  ：", fixed_marks)
print("金鑰漏網？：", "sk-test-123" in fixed)
```
4. **預期看到**：
   - 書附遮蔽後：`客戶 email: [REDACTED_EMAIL]，api_key=sk-test-123，請分流。`；紀錄 `['pattern:email']`；`金鑰漏網？： True`。
   - 補規則後：`客戶 email: [REDACTED_EMAIL]，api_key=[REDACTED_SECRET]，請分流。`；紀錄 `['pattern:email', 'pattern:api_key']`；`金鑰漏網？： False`。
5. **是否呼叫模型**：否

## 第 4 步：竄改一個字，雜湊就對不上（離線版）

1. **標題**：實驗：改掉 span 裡一個字，看防竄改雜湊
2. **目的**：證據信封的雜湊綁住了每個 span 的內容；事後有人改了一個屬性，重算雜湊就會不同。產物本身另存 sha256，稽核者拿原文重算就能驗證。這一步先用假回覆離線演一次，第 6 步再換成真模型。
3. **指令（內嵌 Python）**：
```python
import hashlib
from harnesslab.core import Tracer
reply = "INC-777 為釣魚郵件事件。已隔離受影響帳號。建議輪換相關憑證。"
reply_hash = hashlib.sha256(reply.encode("utf-8")).hexdigest()
tracer = Tracer(run_id="k142-ch07", actor="triage-subagent")
with tracer.span("subagent_call") as span:
    span.attributes["reply_redacted"] = reply
    span.attributes["reply_sha256"] = reply_hash
env = tracer.envelope(artifacts={"reply_sha256": reply_hash}, redactions=["pattern:email"])
h1 = env.tamper_evident_hash()
span.attributes["reply_redacted"] = reply.replace("釣魚", "誤報")   # 竄改一個詞
h2 = env.tamper_evident_hash()
span.attributes["reply_redacted"] = reply                             # 改回來
h3 = env.tamper_evident_hash()
print("原始雜湊：", h1)
print("竄改後  ：", h2)
print("改回後  ：", h3)
print("竄改被發現：", h1 != h2, "｜改回後一致：", h1 == h3)
audit = hashlib.sha256(reply.encode("utf-8")).hexdigest()
print("稽核重算產物雜湊與信封一致：", audit == env.artifact_hashes["reply_sha256"])
fake = hashlib.sha256((reply + "。").encode("utf-8")).hexdigest()
print("多一個句號的版本也一致嗎：", fake == env.artifact_hashes["reply_sha256"])
```
4. **預期看到**：
   - 三個 64 位雜湊；`竄改被發現： True ｜改回後一致： True`（h1 與 h3 相同，因為 `created_at` 在建信封時就固定）。
   - `稽核重算產物雜湊與信封一致： True`；`多一個句號的版本也一致嗎： False`。
5. **是否呼叫模型**：否

## 第 5 步：回歸閘門：快了、準了，安全退步還是擋

1. **標題**：實驗：用 `_regression_report` 和 `_metric_score` 比三個候選
2. **目的**：爬坡要過安全閘門。只要三個安全指標任何一個退步，判定就是 escalate，即使延遲降了、綜合分數還更高也一樣（練習 2 第 6 點＋練習 1 第 4 點的數字概念）。
3. **指令（內嵌 Python）**：
```python
from chapters.ch07.scenario import _regression_report, _metric_score
base = {"task_success": 0.80, "unsafe_block_rate": 0.95, "redaction_recall": 0.90,
        "replay_pass_rate": 1.0, "median_latency_ms": 1200}
cands = {
    "A 延遲降、遮蔽退步": {**base, "median_latency_ms": 960, "redaction_recall": 0.75},
    "B 只降延遲":         {**base, "median_latency_ms": 960},
    "C 更準更快、遮蔽退步": {**base, "median_latency_ms": 960, "redaction_recall": 0.75, "task_success": 0.90},
}
print(f"基準分數 = {_metric_score(base)}")
for name, c in cands.items():
    r = _regression_report(base, c)
    print(f"\n[{name}] 分數 = {_metric_score(c)}  判定 = {r['verdict'].upper()}")
    print("  退步的安全指標：", r["failed_gates"])
    print("  差值：", r["deltas"])
```
4. **預期看到**：
   - `基準分數 = 0.865`。
   - A：分數 `0.859`，判定 `ESCALATE`，退步 `['redaction_recall']`，差值含 `'redaction_recall': -0.15`、`'median_latency_ms': -240`（或 `-240.0`）。
   - B：分數 `0.889`，判定 `PASS`，退步 `[]`。
   - C：分數 `0.894`（**比基準高**），判定仍是 `ESCALATE`，退步 `['redaction_recall']` → 分數高不代表能上線。
5. **是否呼叫模型**：否

## 第 6 步：把真實模型呼叫封進證據信封（練習 2）

1. **標題**：真模型：子代理呼叫 → 輸入輸出都遮蔽 → 封信封 → 竄改測試
2. **目的**：把一次真的 `claude -p` 呼叫變成可稽核紀錄。重點是遮蔽要同時套在 prompt 和回覆：模型常把上下文裡的 email／金鑰原樣抄回來，只遮 prompt 是常見漏洞。檔案裡不留原文，只留遮蔽後內容、欄位名與雜湊。
3. **指令（內嵌 Python）**：
```python
import sys, re, hashlib
from pathlib import Path
sys.path.insert(0, "..")
from llm_agent import ask
from harnesslab.core import Tracer
from chapters.ch07.scenario import _redact_payload

API_KEY = re.compile(r"api_key\s*[=:]\s*[A-Za-z0-9_\-]+", re.I)
def redact_text(t):
    out, marks = _redact_payload(t)
    new = API_KEY.sub("api_key=[REDACTED_SECRET]", out)
    if new != out:
        marks.append("pattern:api_key")
    return new, marks

RAW = ["amy@example.com", "sk-test-123"]
prompt = ("你是資安分流代理。請用繁體中文、剛好 3 句話，替下面這則虛構事故寫摘要。\n"
          "事故 INC-777：財務部員工點了釣魚連結，可能外洩登入憑證。\n"
          "客戶 email: amy@example.com，api_key=sk-test-123")
tracer = Tracer(run_id="k142-ch07", actor="triage-subagent")
with tracer.span("subagent_call", tool="claude -p") as span:
    try:
        reply = ask(prompt)
    except Exception as exc:
        reply = f"（呼叫失敗：{exc}）"
    p_red, p_marks = redact_text(prompt)
    r_red, r_marks = redact_text(reply)
    reply_hash = hashlib.sha256(reply.encode("utf-8")).hexdigest()
    span.attributes.update(prompt_redacted=p_red, reply_redacted=r_red, reply_sha256=reply_hash)
redactions = sorted({f"prompt:{m}" for m in p_marks} | {f"reply:{m}" for m in r_marks})
env = tracer.envelope(artifacts={"reply_sha256": reply_hash}, redactions=redactions)
h1 = env.tamper_evident_hash()
span.attributes["reply_redacted"] = r_red[:-1] + ("X" if r_red[-1:] != "X" else "Y")
h2 = env.tamper_evident_hash()
span.attributes["reply_redacted"] = r_red
audit_ok = hashlib.sha256(reply.encode("utf-8")).hexdigest() == env.artifact_hashes["reply_sha256"]
echoed = [s for s in RAW if s in reply]
leak_in_trace = [s for s in RAW if s in str(span.attributes)]

print("遮蔽後回覆：\n ", r_red)
print("\n遮蔽紀錄      ：", redactions)
print("模型回顯原文  ：", "有（" + "、".join("email" if "@" in s else "api_key" for s in echoed) + "）" if echoed else "沒有")
print("軌跡裡仍有原文：", bool(leak_in_trace))
print("雜湊 h1       ：", h1)
print("竄改後 h2     ：", h2)
print("竄改被發現    ：", h1 != h2)
print("稽核驗證產物  ：", audit_ok)

od = Path("../ch07/interactive"); od.mkdir(parents=True, exist_ok=True)
md = "\n".join([
    "# ch07 traced_agent 紀錄", "",
    "## 遮蔽前後對照", "- prompt：email、api_key 已遮蔽",
    f"- 遮蔽欄位：{', '.join(redactions) or '（無）'}", "",
    "## 遮蔽後 prompt", "```", p_red, "```", "",
    "## 遮蔽後回覆", "```", r_red, "```", "",
    "## 雜湊", f"- 回覆 sha256：{reply_hash}", f"- 信封雜湊：{h1}", f"- 竄改後：{h2}",
    f"- 竄改被發現：{h1 != h2}", f"- 稽核重算一致：{audit_ok}", "",
    f"## 模型回顯檢查", f"- 回覆有沒有照抄 email／api_key：{'有' if echoed else '沒有'}",
    f"- 遮蔽有沒有擋住：{'有' if not leak_in_trace else '沒有'}",
])
assert not any(s in md for s in RAW), "原文不可出現在檔案裡"
(od / "traced_agent.md").write_text(md, encoding="utf-8")
print("\n已存：practice/ch07/interactive/traced_agent.md（檢查過不含原文）")
```
4. **預期看到**：
   - 一段約 3 句的繁中事故摘要（遮蔽後）；若模型照抄了聯絡資料，會看到 `[REDACTED_EMAIL]` 或 `api_key=[REDACTED_SECRET]`，不會看到 `amy@example.com`／`sk-test-123`。
   - 遮蔽紀錄至少有 `prompt:pattern:api_key`、`prompt:pattern:email`；若模型回顯，還會多 `reply:pattern:...`。
   - `模型回顯原文` 為「有（…）」或「沒有」（兩者都算對，視模型而定）；`軌跡裡仍有原文： False`。
   - `竄改被發現 ： True`、`稽核驗證產物 ： True`；最後印出已存檔訊息，且沒有 AssertionError。
   - 若 `claude -p` 失敗，回覆會是「（呼叫失敗：…）」，其餘流程照樣跑完（測試者據此判斷是環境問題）。
5. **是否呼叫模型**：是（`ask` 1 次）

## 第 7 步：跑書附第 7 章完整情境，拆開證據（練習 1）

1. **標題**：跑書附 ch07：遮蔽、信封、重播、回歸、爬坡、自我改進
2. **目的**：看作者的完整情境怎麼把六件事串起來，並親手驗證：從 JSON 重算每個產物雜湊都跟信封一致；改掉一個產物就對不上。順便把練習 1 的重點整理成 `evidence-reading.md`。
3. **指令（內嵌 Python）**：
```python

from pathlib import Path
from chapters.ch07.scenario import _stable_hash
out = subprocess.run([sys.executable, "-m", "harnesslab.cli", "run", "ch07", "--json"],
                     capture_output=True, text=True, encoding="utf-8")
data = json.loads(out.stdout)[0]
art = data["artifacts"]
od = Path("../ch07/interactive"); od.mkdir(parents=True, exist_ok=True)
(od / "run.json").write_text(out.stdout, encoding="utf-8")

print(f"通過={data['passed']} 分數={data['score']}")
```
