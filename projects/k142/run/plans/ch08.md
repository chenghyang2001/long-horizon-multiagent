## 已讀原始碼確認的名稱（供實作者核對）

- `harnesslab/core.py`
  - `RuntimeController()`：屬性 `paused: set`、`killed: set`、`checkpoints: dict[id, Checkpoint]`、`policy_overlays: dict[run_id, {"overlay": dict, "expires_at": float}]`。

## 第 1 步：認識主角 RuntimeController

1. **標題**：認識主角：RuntimeController 的五個把手
2. **目的**：代理跑起來之後，harness 手上要有把手：存檢查點、暫停、終止、注入臨時政策、從檢查點恢復。先看每個把手回傳什麼決策，以及它改了控制器裡的哪個欄位。
3. **指令（內嵌 Python）**：
```python
from harnesslab.core import RuntimeController
rt = RuntimeController()
run_id = "refund-run"
print("一開始：paused=", rt.paused, " killed=", rt.killed, " checkpoints=", list(rt.checkpoints), " overlays=", list(rt.policy_overlays))
ck = rt.checkpoint(run_id, {"step": 2, "done": ["ORD-1001", "ORD-1002"]}, "training-policy-v1", "evidence-hash-demo")
print("檢查點：", ck.checkpoint_id, "| run_id =", ck.run_id, "| 政策版本 =", ck.policy_version, "| state =", ck.state)
acts = [
    ("pause", rt.pause(run_id, "fraud alert")),
    ("kill", rt.kill("child-worker", "子任務一直重試")),
    ("inject_policy", rt.inject_policy(run_id, {"block_categories": ["gift_card"], "expires_after_step": 5}, ttl_seconds=60)),
]
for name, d in acts:
    print(f"  {name:<14}→ {d.decision.value.upper():<6} 控制={d.controls}  原因：{d.reason}")
print("暫停中：", rt.paused, " 已終止：", rt.killed)
item = rt.policy_overlays[run_id]
print("臨時政策：", item["overlay"], "| 另外記了 expires_at（秒）：", "expires_at" in item)
state = rt.resume_from(ck.checkpoint_id)
print("恢復後拿回的 state：", state, "| 暫停中：", rt.paused)
```
4. **預期看到**：
   - 一開始四個欄位都是空的（`set()`、`set()`、`[]`、`[]`）。
   - 檢查點 id 形如 `ckpt_` 加 16 位十六進位；state 就是 `{'step': 2, 'done': ['ORD-1001', 'ORD-1002']}`。
   - `pause → WARN 控制=('runtime_steering', 'pause') 原因：run paused: fraud alert`。
   - `kill → DENY 控制=('runtime_steering', 'kill_switch') 原因：run killed: 子任務一直重試`。
   - `inject_policy → ALLOW 控制=('runtime_steering', 'policy_overlay') 原因：bounded policy overlay injected`。
   - 暫停中 `{'refund-run'}`、已終止 `{'child-worker'}`；`另外記了 expires_at（秒）： True`。
   - 恢復後 state 與檢查點相同，`暫停中： set()`（resume_from 會清掉暫停）。
5. **是否呼叫模型**：否

## 第 2 步：觀察與隔離：惡意留言不准帶方向

1. **標題**：觀察 → 隔離 → 警示：用 ContextFirewall 擋下票券裡的惡意留言

## 第 3 步：陷阱：pause 不會自己擋，gateway 還會放行個資信

1. **標題**：陷阱：暫停只是記一筆，真正擋信的是有期限的臨時政策
2. **目的**：兩個常見誤會。第一，`pause` 只是把 run_id 放進一個集合，gateway 根本不看它，harness 每一步都要自己檢查。第二，書附 gateway 對含 PII 的客戶信是 ALLOW，在 overlay 生效期間（第 8 步以前）才擋得住；到期後同一封信又會放行，所以情境到期後只寄遮蔽過的公開版本。這也是練習 1 第 2 題：`_overlay_active` 只用步數判斷。
3. **指令（內嵌 Python）**：
```python
from harnesslab.core import Harness, ToolCall, DataClass, ActionRisk
from chapters.ch08.scenario import _overlay_active
h = Harness()
run_id = "incident-run"
email = ToolCall(tool="send_customer_email", args={"body": "raw private incident notes"},
                 data_class=DataClass.PII, side_effect=ActionRisk.EXTERNAL_COMMUNICATION, intent="notify customer")
ck = h.runtime.checkpoint(run_id, {"step": 4}, "training-policy-v1", "demo")
h.runtime.pause(run_id, "hostile context")
d = h.gateway.check(email)
print("暫停中？", run_id in h.runtime.paused, "| gateway 對含個資客戶信：", d.decision.value.upper(), "-", d.reason)
print("→ gateway 不看 paused，也允許 PII 寄出\n")
h.runtime.inject_policy(run_id, {"deny_tools": ["send_customer_email"], "deny_data": ["pii", "confidential"],
                                 "expires_after_step": 8}, ttl_seconds=60)
ov = h.runtime.policy_overlays[run_id]["overlay"]
def steer(step, call):
    if run_id in h.runtime.paused:
        return "HOLD（暫停中，不執行）"
    if _overlay_active(h, run_id, step) and call.tool in ov["deny_tools"] and call.data_class.value in ov["deny_data"]:
        return "DENY（臨時政策生效）"
    return h.gateway.check(call).decision.value.upper() + "（回到一般 gateway）"
print(f"  第 5 步  overlay 生效={_overlay_active(h, run_id, 5)!s:<5} → {steer(5, email)}")
h.runtime.resume_from(ck.checkpoint_id)
for step in (7, 8, 9, 12):
    print(f"  第 {step:<2} 步 overlay 生效={_overlay_active(h, run_id, step)!s:<5} → {steer(step, email)}")
```
4. **預期看到**：
   - `暫停中？ True | gateway 對含個資客戶信： ALLOW - tool gateway accepted call`。
   - 第 5 步：`overlay 生效=True  → HOLD（暫停中，不執行）`。
   - 第 7、8 步：`overlay 生效=True  → DENY（臨時政策生效）`。
   - 第 9、12 步：`overlay 生效=False → ALLOW（回到一般 gateway）`。教練要點出：到期後含個資的信又能寄了，所以書附第 12 步改寄 `DataClass.PUBLIC` 的遮蔽版本。
5. **是否呼叫模型**：否

## 第 4 步：實驗：ttl_seconds=0，政策還算生效嗎？

1. **標題**：實驗：秒數期限記下來了，但沒人去檢查
2. **目的**：練習 2 第 5 點。`inject_policy` 會記 `expires_at`（秒），但 `RuntimeController` 裡沒有任何地方讀它；書附 `_overlay_active` 也只看步數。期限要由 harness 在每一步自己判斷。最後自己寫一個步數和秒數都檢查的版本。
3. **指令（內嵌 Python）**：
```python
import time, inspect
from harnesslab.core import Harness, RuntimeController
from chapters.ch08.scenario import _overlay_active
h = Harness()
run_id = "refund-run"
h.runtime.inject_policy(run_id, {"block_categories": ["gift_card"], "expires_after_step": 5}, ttl_seconds=0)
time.sleep(0.05)
item = h.runtime.policy_overlays[run_id]
now = time.time()
print("expires_at =", round(item["expires_at"], 3), " now =", round(now, 3), " 以秒數看已過期？", now >= item["expires_at"])
print("overlay 還留在 policy_overlays？", run_id in h.runtime.policy_overlays)
print("書附 _overlay_active(step=3)：", _overlay_active(h, run_id, 3), "← 只看 expires_after_step")
src = inspect.getsource(RuntimeController)
print("RuntimeController 原始碼裡 expires_at 出現次數：", src.count("expires_at"), "（只在 inject_policy 寫入，沒有讀取）")
def overlay_active(step):
    it = h.runtime.policy_overlays.get(run_id)
    if it is None:
        return False
    if time.time() >= it["expires_at"]:
        return False
    return step <= int(it["overlay"].get("expires_after_step", -1))
print("自己寫的版本（步數＋秒數都檢查）step=3：", overlay_active(3))
```
4. **預期看到**：
   - `以秒數看已過期？ True`（now 比 expires_at 大約 0.05 秒）。
   - `overlay 還留在 policy_overlays？ True`。
   - `書附 _overlay_active(step=3)： True ← 只看 expires_after_step`。
   - `RuntimeController 原始碼裡 expires_at 出現次數： 1`。
   - `自己寫的版本（步數＋秒數都檢查）step=3： False`。
5. **是否呼叫模型**：否

## 第 5 步：陷阱與補償：檢查點要深拷貝，回滾要留墓碑

1. **標題**：陷阱：淺拷貝的檢查點會被汙染；補償回滾和刪掉有什麼不同
2. **目的**：恢復要靠檢查點，但 `RuntimeController.checkpoint` 存的是 `dict(state)` 淺拷貝，之後改原 state 裡的 list，檢查點也跟著被改。書附情境用 `_clone_state` 深拷貝避開。接著看補償：草稿被 `rollback` 之後讀不到，但帳本裡還有這筆紀錄和原因（練習 1 第 4 題）。
3. **指令（內嵌 Python）**：
```python
from harnesslab.core import RuntimeController, MemoryFirewall, DataClass, TrustTier
from chapters.ch08.scenario import _clone_state
state = {"run_id": "r1", "step": 4, "phase": "draft", "completed": ["read_ticket"], "remaining": ["notify_owner"],
         "quarantined": [], "blocked": [], "compensations": [], "notices": []}
raw = RuntimeController().checkpoint("r1", state, "training-policy-v1", "h")
safe = RuntimeController().checkpoint("r1", _clone_state(state), "training-policy-v1", "h")
state["step"] = 8
state["completed"].append("send_customer_email（被擋的那步）")
print("原 state 之後跑到：step =", state["step"], " completed =", state["completed"])
print("淺拷貝檢查點：     step =", raw.state["step"], " completed =", raw.state["completed"], "← list 被汙染")
print("深拷貝檢查點：     step =", safe.state["step"], " completed =", safe.state["completed"])
print()
mem = MemoryFirewall()
d = mem.propose_write(key="customer_notice_draft", value="Draft a redacted incident notice only after runtime recovery.",
                      tenant="training", data_class=DataClass.INTERNAL, trust_tier=TrustTier.TENANT, source="ch08-drill")
rid = mem.ledger[-1].record_id
allow = frozenset({DataClass.INTERNAL})
print("寫草稿：", d.decision.value.upper(), d.reason, "| 讀得到幾筆：", len(mem.read("customer_notice_draft", "training", allow)))
r = mem.rollback(rid, "blocked outbound communication invalidated the draft")
rec = mem.ledger[-1]
print("補償：", r.decision.value.upper(), r.reason, "| 讀得到幾筆：", len(mem.read("customer_notice_draft", "training", allow)))
print("帳本仍有幾筆：", len(mem.ledger), "| deleted =", rec.deleted, "| 墓碑原因：", rec.tombstone_reason)
```
4. **預期看到**：
   - 原 state：`step = 8`，completed 有兩項。
   - 淺拷貝檢查點：`step = 4`（數字沒變），但 `completed` **也多了** `send_customer_email（被擋的那步）`，後面印 `← list 被汙染`。
   - 深拷貝檢查點：`step = 4  completed = ['read_ticket']`。
   - `寫草稿： ALLOW memory record mem_ed92c76d3757c571 stored | 讀得到幾筆： 1`（與書附情境同 id，因為 key／value／tenant 相同）。
   - `補償： ALLOW memory record mem_ed92c76d3757c571 tombstoned | 讀得到幾筆： 0`。
   - `帳本仍有幾筆： 1 | deleted = True | 墓碑原因： blocked outbound communication invalidated the draft`。
5. **是否呼叫模型**：否

## 第 6 步：真模型：退款跑到一半，主管注入臨時政策（練習 2）

1. **標題**：真模型：claude -p 產生 6 筆退款，半途暫停、注入 gift_card 禁令、恢復、防重複撥款
2. **目的**：把前幾步串成一次真實操控。子代理先列出退款清單；處理完第 2 筆後發生詐騙警報，harness 存檢查點、暫停、注入「第 5 步前不准退 gift_card」的臨時政策，再恢復。第 2 筆在恢復後故意重送一次，冪等鍵會讓它跳過，不會重複撥款。順便記錄 ttl=0 的觀察。結果存成 `refund_steering.md`。
3. **指令（內嵌 Python）**：
```python
import sys, json, time
from pathlib import Path
sys.path.insert(0, "..")
from llm_agent import ask_json
from harnesslab.core import RuntimeController

prompt = ("你是客服退款代理。請處理 6 筆虛構退款：自己編訂單號（ORD-1001 起，不重複）、金額（新台幣整數）、"
          "類別（從 electronics、apparel、books、gift_card 選），其中至少 2 筆類別必須是 \"gift_card\"。"
          "輸出格式：{\"refunds\":[{\"order\":\"ORD-1001\",\"amount\":1200,\"category\":\"books\",\"action\":\"refund\"}]}，剛好 6 筆。")
source = "claude -p"
try:
    refunds = ask_json(prompt)["refunds"]
    if len(refunds) < 6:
        raise ValueError("退款不足 6 筆")
except Exception as exc:
    source = "離線備用清單（呼叫失敗：" + str(exc)[:60] + "）"
    refunds = [{"order": f"ORD-100{i}", "amount": a, "category": c, "action": "refund"} for i, (a, c) in
               enumerate([(1200, "books"), (800, "gift_card"), (500, "gift_card"), (2300, "electronics"), (300, "gift_card"), (1000, "gift_card")], 1)]
refunds = refunds[:6]
for r in refunds:
    r["order"] = str(r.get("order"))
    r["category"] = str(r.get("category", "")).strip().lower().replace(" ", "_").replace("-", "_")

rt = RuntimeController()
run_id = "refund-run"
paid = {}   # 冪等鍵：訂單號 → 撥款步數（模擬金流端紀錄，不會隨檢查點回捲）
rows = []
state = {"step": 0, "refunded": []}
```
