## 第 2 步：練習 1 之一：從 responseSchema 抽出回覆契約

**目的**：用正規表示式從 route.ts 第 23～45 行的 zod `responseSchema` 抽出欄位表，看出「一個 JSON 同時帶回答、思考、情緒、追問、分類、轉真人」。也要看到 `matched_categories` 只驗「字串陣列」，不驗內容。

**要跑的內嵌 Python**：

```python
import os, re, sys
sys.path.insert(0, os.getcwd())
from qs_source import read_text

REL = "customer-support-agent/app/api/chat/route.ts"
Q = chr(34)
lines = read_text(REL).splitlines()
start = next(i for i, s in enumerate(lines) if "const responseSchema = z.object" in s)
end = next(i for i in range(start, len(lines)) if lines[i].startswith("});"))
print("responseSchema 區塊：第 {} ～ {} 行".format(start + 1, end + 1))
print()

heads = []
for i in range(start + 1, end):
    m = re.match(r"  (\w+): z", lines[i])
    if m:
        heads.append((i, m.group(1)))

fields, nested, moods = [], [], []
for k, (i, name) in enumerate(heads):
    j = heads[k + 1][0] if k + 1 < len(heads) else end
    chunk = "\n".join(lines[i:j])
    t = re.search(r"[.](string|enum|array|object|boolean)[(]", chunk).group(1)
    if t == "array":
        t = "array(" + re.search(r"z[.]array[(]z[.](\w+)[(]", chunk).group(1) + ")"
    opt = chunk.strip().rstrip(",").endswith(".optional()")
    fields.append((name, t, "選填" if opt else "必填", i + 1))
    if t == "object":
        for m in re.finditer(r"(\w+): z[.](\w+)[(][)]([.]optional[(][)])?", chunk):
            if m.group(1) != name:
                nested.append((name + "." + m.group(1), m.group(2), "選填" if m.group(3) else "必填"))
    if t == "enum":
        moods = re.findall(Q + r"(\w+)" + Q, chunk)

print("{:<20} | {:<14} | {:<6} | {}".format("欄位", "型別", "必填/選填", "行號"))
print("-" * 56)
for name, t, req, no in fields:
    print("{:<20} | {:<14} | {:<6} | {}".format(name, t, req, no))
print()
print("巢狀欄位：")
for name, t, req in nested:
    print("  {:<34} | {:<8} | {}".format(name, t, req))
print()
n_req = sum(1 for f in fields if f[2] == "必填")
print("頂層欄位 {} 個：必填 {}、選填 {}".format(len(fields), n_req, len(fields) - n_req))
print("user_mood 允許值（{} 個）：{}".format(len(moods), ", ".join(moods)))
print()
print("注意：matched_categories 只驗 array(string)，沒有檢查代號在不在分類表；thinking 只是一般字串欄位，不是延伸思考。")
```

**預期看到什麼**：

- `responseSchema 區塊：第 23 ～ 45 行`
- 欄位表剛好 7 列（欄位｜型別｜必填/選填｜行號）：
  - `response | string | 必填 | 24`
  - `thinking | string | 必填 | 25`
  - `user_mood | enum | 必填 | 26`
  - `suggested_questions | array(string) | 必填 | 34`
  - `debug | object | 必填 | 35`
  - `matched_categories | array(string) | 選填 | 38`
  - `redirect_to_agent | object | 選填 | 39`
- 巢狀欄位 3 列：`debug.context_used | boolean | 必填`、`redirect_to_agent.should_redirect | boolean | 必填`、`redirect_to_agent.reason | string | 選填`。
- `頂層欄位 7 個：必填 5、選填 2`
- `user_mood 允許值（6 個）：positive, neutral, negative, curious, frustrated, confused`

**是否呼叫模型**：否。
