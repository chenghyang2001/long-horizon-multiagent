## 第 2 步：練習 1 之一：7 個 @override 方法各直接送了哪些 CDP 指令（表一）

**目的**：不執行官方程式，只把 cdp_browser.py 當純文字分析，看出五個工具＋close＋_browser_state 各自直接送了哪個 CDP 指令、用了哪段 JS 常數；並發現 read_page、get_page_text 根本沒直接呼叫 `_send`，而是經 `_evaluate` 用 `Runtime.evaluate` 在頁面裡跑 JS。

**要跑的內嵌 Python**：

```python
import os, re, sys
sys.path.insert(0, os.getcwd())
from qs_source import read_text, grep

Q = chr(34)
CDP = "browser-toolset/python/cdp_browser.py"
lines = read_text(CDP).splitlines()
JS = ["READ_PAGE", "RESOLVE_REF", "PAGE_INFO", "PAGE_TEXT"]
SEND = re.compile("self[.]_send[(]" + Q + "([A-Za-z]+[.][A-Za-z]+)" + Q)
DEF = re.compile("    def ([A-Za-z_]+)[(]")

def methods():
    out = []
    for j, line in enumerate(lines):
        m = DEF.match(line)
        if not m:
            continue
        k = j + 1
        while k < len(lines):
            nxt = lines[k]
            if nxt.startswith("    @") or nxt.startswith("    def ") or (nxt and not nxt.startswith(" ")):
                break
            k += 1
        deco = j if j > 0 and lines[j - 1].strip() == "@override" else None
        out.append({"name": m.group(1), "def": j + 1, "end": k, "override": deco, "body": "\n".join(lines[j + 1:k])})
    return out

def direct(body):
    found = SEND.findall(body)
    seen = []
    for f in found:
        if f not in seen:
            seen.append(f)
    return ", ".join(s + ("×" + str(found.count(s)) if found.count(s) > 1 else "") for s in seen) or "-"

def consts(body):
    return ", ".join(c for c in JS if c in body) or "-"

def indirect(body):
    if "self._evaluate(" in body:
        return "Runtime.evaluate（經 _evaluate）"
    if "self._page_info(" in body:
        return "Runtime.evaluate（經 _page_info）"
    return "-"

ms = methods()
ov = [m for m in ms if m["override"]]
print("cdp_browser.py 共", len(lines), "行；grep 到", len(grep(CDP, "^    @override")), "行 @override，對應方法", len(ov), "個")
print()
print("【表一】@override 方法 → 直接送的 CDP 指令")
print("{:<15} | {:<15} | {:<28} | {:<12} | {}".format("方法", "行號(@/def)", "直接送的 CDP 指令", "JS 常數", "間接用到"))
print("-" * 110)
for m in ov:
    print("{:<15} | {:<15} | {:<28} | {:<12} | {}".format(m["name"], "{}/{}".format(m["override"], m["def"]), direct(m["body"]), consts(m["body"]), indirect(m["body"])))
print()
for name in ("read_page", "get_page_text"):
    body = [m for m in ms if m["name"] == name][0]["body"]
    print("  {} 直接呼叫 _send：{}".format(name, "是" if "self._send(" in body else "否"))
print()
print("【補充】不是 @override、但直接送指令或用到 JS 常數的方法")
for m in ms:
    if m["override"]:
        continue
    d, c = direct(m["body"]), consts(m["body"])
    if d != "-" or c != "-":
        print("  {:<12} 第 {:>3} 行 | 指令：{} | JS 常數：{}".format(m["name"], m["def"], d, c))
print()
print("JS 常數定義在檔尾：")
for no, line in grep(CDP, "^(READ_PAGE|RESOLVE_REF|PAGE_INFO|PAGE_TEXT) = "):
    print("  第 {} 行：{}".format(no, line.strip()[:60]))
for no, line in grep(CDP, "for kind in"):
    print("left_click 第 {} 行：{}".format(no, line.strip()))
print("→ 程式裡寫了 2 處 Input.dispatchMouseEvent，執行時送 3 個滑鼠事件：mouseMoved、mousePressed、mouseReleased。")
```

- 第一行：`cdp_browser.py 共 295 行；grep 到 7 行 @override，對應方法 7 個`。
- 表一七列（順序固定）：
  - `close | 130/131 | Browser.close | - | -`
  - `navigate | 201/202 | Page.navigate | - | Runtime.evaluate（經 _page_info）`
  - `read_page | 225/226 | - | READ_PAGE | Runtime.evaluate（經 _evaluate）`

  - `_browser_state | 254/255 | - | - | Runtime.evaluate（經 _page_info）`
- `read_page 直接呼叫 _send：否`、`get_page_text 直接呼叫 _send：否`。
