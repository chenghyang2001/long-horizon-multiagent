# K143 第 10 章互動演練規劃：Effort 旋鈕就是成本旋鈕

- 本章主角：`effort/effort_router.py`（`LEVELS`、`effort_for(task)`、`run(task)`、`main()`、模組層 `client = Anthropic()`）與 `skills/effort-router/SKILL.md`
- 輔助模組（都讀過原始碼確認存在）：`migration/migration_linter.py` 的 `lint(req)`、`fable_scanner/monitor.py` 的 `PRICE_PER_M`／`analyze(lines)`／`print_report(stats)`、`practice/claude_cli_client.py` 的 `_build_command(exe, model, system_file, effort, web_search)`、`Anthropic()`、`calls_made()`
- 執行慣例：照 `ch03.sh`／`ch09.sh` 的 `sh_run`／`py_run`，cwd 是 `practice/fable5`；`py_run` 開頭已經 `sys.path.insert(0, ".."); import claude_cli_client; claude_cli_client.install()`
- **一定要先 install 再匯入**：`effort_router.py` 第 20 行一 import 就 `client = Anthropic()`
- **不可直接執行** `effort/effort_router.py`（`main()` 會一次跑 3 個任務）；一律 `import effort.effort_router as er`
- 產出全寫到 `../ch10/interactive/`（也就是 `practice/ch10/interactive/`）；effort_router 本身不寫檔，不需要改路徑常數
- 呼叫模型：只有第 6 步（3 次）和第 7 步（2 次），共 5 次。腳本頂端 `export K143_CLI_MAX_CALLS=6`（每步是獨立行程，計數會重來）
- **不要設 `K143_CLI_MODEL`**：`monitor.PRICE_PER_M` 只認 `claude-fable-5` 這類完整名稱，換成 haiku 成本會變空白（ch05 也是這樣處理）
- 引號與 heredoc 注意：
  - `P='...'` 是單引號字串，裡面**不可出現單引號**（Python 一律用雙引號；內層 heredoc 也不能寫 `<<'EOF'`）
  - `py_run` 的 heredoc 沒加引號，內嵌 Python 不可出現錢字號與反引號（金額一律寫「美元」）；程式經 `$1` 展開塞進 heredoc，展開結果不再處理反斜線，所以 `"\n"` 照原樣寫即可

## 第 3 步：不設 effort 會怎樣——linter 提醒＋全 repo 的 effort 分布

1. **標題**：機隊健檢：linter 抓「沒設 effort」，再數全 repo 寫死了幾個 effort
2. **目的**：先用第 7 章的 `lint()` 看「沒設 effort」被標成 info、預設就是 high；再掃 fable5/ 所有 `.py` 數 `effort="..."` 寫死的地方，發現大家各自寫死、沒有人呼叫 `effort_for()`——政策沒有集中，改一次就得改很多處。
3. **指令**（`py_run`）：

   ```python
   import re
   from collections import Counter
   from pathlib import Path
   from migration.migration_linter import lint
   req = {"model": "claude-fable-5", "fallbacks": [{"model": "claude-opus-4-8"}],
          "messages": [{"role": "user", "content": "hi"}]}
   print("──── 一個沒設 effort 的請求丟給 lint() ────")
   for field, sev, msg in lint(req):
       print("  " + sev.upper().ljust(5) + " " + field + "：" + msg)
   print()
   rx = re.compile("effort=.(low|medium|high|xhigh|max).")
   counts, where, users = Counter(), {}, []
   for p in sorted(Path(".").rglob("*.py")):
       text = p.read_text(encoding="utf-8")
       for lvl in rx.findall(text):
           counts[lvl] += 1
           where.setdefault(lvl, set()).add(p.parts[0])
       if "effort_for" in text and p.name != "effort_router.py":
           users.append(str(p))
   print("──── fable5/ 裡寫死 effort=\"...\" 的次數 ────")
   for lvl in ("low", "medium", "high", "xhigh", "max"):
       print("  " + lvl.ljust(6) + str(counts[lvl]).rjust(3) + " 次｜" + ", ".join(sorted(where.get(lvl, []))))
   print("  合計 " + str(sum(counts.values())) + " 處")
   print()
   print("effort_router.py 以外有呼叫 effort_for 的檔案：" + (", ".join(users) or "0 個"))
   ```

4. **預期看到**：
   - lint 只回一條：`INFO  output_config.effort：No effort set. Fable 5 defaults to 'high'; set it explicitly so a fleet-wide change is one edit, not many.`
   - 分布（已用 Grep 對書附原始碼核過）：`low 3`（agentic_soc、deep_research、job_packet）、`medium 5`（agentic_soc、deep_research、job_packet、projects）、`high 10`（fable_scanner、job_packet、projects、refusal）、`xhigh 5`（deep_research、projects）、`max 0`，合計 23 處
   - 最後一行：`effort_router.py 以外有呼叫 effort_for 的檔案：0 個`
5. **是否呼叫模型**：否

## 第 4 步：run() 到底送出什麼——假 client 攔截，再看轉接層丟掉哪些

1. **標題**：攔截 run() 的請求本體：output_config.effort 怎麼傳、轉接層又怎麼轉
2. **目的**：把 `er.client` 換成會記錄的假 client（不呼叫模型），看 `run()` 送出的 `output_config`、`betas`、`fallbacks`；再用轉接層的 `_build_command()` 看 effort 變成 `claude -p --effort`，而拼錯的 effort（例如 `extreme`）會被默默丟掉、不報錯。
3. **指令**（`py_run`）：

   ```python
   import copy
   from types import SimpleNamespace as NS
   import claude_cli_client as cc
   import effort.effort_router as er
   sent = []
   def fake_create(**kw):
       sent.append(copy.deepcopy(kw))
       return NS(usage=NS(output_tokens=42))       # 假裝回 42 個輸出 token
   er.client = NS(beta=NS(messages=NS(create=fake_create)))   # run() 讀模組層 client，換掉就生效
   r = er.run({"kind": "audit", "prompt": "替部署代理做威脅評估"})
   print("run() 回傳：" + str(r))
   print("送出的欄位：" + ", ".join(sent[0]))
   print("  output_config = " + str(sent[0]["output_config"]))
   print("  betas         = " + str(sent[0]["betas"]))
   print("  fallbacks     = " + str(sent[0]["fallbacks"]))
   print("  max_tokens    = " + str(sent[0]["max_tokens"]))
   print()
   print("──── 轉接層把 effort 轉成 CLI 參數 ────")
   for lvl in ("low", "xhigh", "extreme"):
       cmd = cc._build_command("claude", er.FABLE, "sys.txt", lvl, False)
       if "--effort" in cmd:
           i = cmd.index("--effort")
           tail = str(cmd[i:i + 2])
       else:
           tail = "（沒有 --effort，CLI 用自己的預設）"
       print("  effort=" + lvl.ljust(8) + " → " + tail)
   print()
   print("轉接層會忽略：betas、fallbacks、max_tokens（見 _Messages.create 的 **ignored）")
   ```

4. **預期看到**：
   - `run() 回傳：{'kind': 'audit', 'effort': 'xhigh', 'output_tokens': 42}`
   - 送出的欄位：`model, max_tokens, output_config, betas, fallbacks, messages`
   - `output_config = {'effort': 'xhigh'}`、`betas = ['server-side-fallback-2026-06-01']`、`fallbacks = [{'model': 'claude-opus-4-8'}]`、`max_tokens = 2048`
   - 轉接層：`low → ['--effort', 'low']`、`xhigh → ['--effort', 'xhigh']`、`extreme → （沒有 --effort，CLI 用自己的預設）`
5. **是否呼叫模型**：否

## 第 5 步：動手寫自己的路由政策 my_router.py（含 assert）

1. **標題**：動手改：複製 effort_for() 成自己的版本，加 3 種本書演練會遇到的任務
2. **目的**：把作者的「一個函式一處修改」變成自己的政策：先正規化 kind（補第 2 步大小寫缺口），加入 `grade`（審查者，low）、`lint-explain`（解釋 linter 結果，medium）、`write-report`（寫演練報告，high）、`threat-model`（xhigh），每種附一行理由，底部用 assert 驗證。檔案寫到 `ch10/interactive/`，不碰 fable5/。
3. **指令**（`sh_run`）。內層 heredoc 用不加引號的 `<<EOF`：外層 `P='...'` 是單引號字串，寫 `<<'EOF'` 會把它截斷；下面這段 Python 沒有錢字號、反引號、反斜線，所以不加引號也不會被展開：

   ```bash
   cat > ../ch10/interactive/my_router.py <<EOF
   """第 10 章演練：我的 effort 路由政策（由書附 effort_for 複製改寫）"""
   POLICY = {
       # 任務類型: (effort, 為什麼)
       "classify":       ("low",    "只要選一個標籤，多想不會更準"),
       "extract":        ("low",    "格式擷取，答案就在輸入裡"),
       "format":         ("low",    "純轉換，不需要推理"),
       "grade":          ("low",    "審查者只核對產出和證據，README 建議 low"),
       "summarize":      ("medium", "要挑重點，但不需要長推論"),
       "lint-explain":   ("medium", "把 linter 的規則說成白話，規則已經定好"),
       "chat":           ("medium", "一般問答，使用者在等"),
       "write-report":   ("high",   "演練報告要組織多步結果，用 API 預設"),
       "migrate":        ("xhigh",  "一次到位的遷移，錯了代價高"),
       "audit":          ("xhigh",  "稽核要找出沒想到的路徑"),
       "threat-model":   ("xhigh",  "攻擊面要窮舉，值得付最高價"),
   }
   DEFAULT = "high"

   def my_effort_for(task):
       """先把 kind 轉小寫去空白，再查表；查不到用 high"""
       kind = str(task.get("kind") or "").strip().lower()
       return POLICY.get(kind, (DEFAULT, "表上沒有，落到預設"))[0]

   if __name__ == "__main__":
       for kind, (lvl, why) in POLICY.items():
           print(kind.ljust(14) + lvl.ljust(7) + why)
       assert my_effort_for({"kind": "grade"}) == "low"
       assert my_effort_for({"kind": "lint-explain"}) == "medium"
       assert my_effort_for({"kind": "write-report"}) == "high"
       assert my_effort_for({"kind": "threat-model"}) == "xhigh"
       assert my_effort_for({"kind": "Classify "}) == "low"     # 第 2 步的大小寫缺口已補
       assert my_effort_for({}) == "high"
       assert my_effort_for({"kind": "sumarize"}) == "high"     # 拼錯仍落到預設：政策只能防呆，不能猜
       print("全部 7 個 assert 通過")
   EOF
   python ../ch10/interactive/my_router.py | tee ../ch10/interactive/my-router.txt
   echo
   echo "已寫入 ../ch10/interactive/my_router.py 與 my-router.txt"
   ```

## 第 6 步：真的跑 er.run() 三個任務（呼叫模型 3 次）

1. **標題**：真的跑路由：classify／summarize／audit 各一次，量真實的 output_tokens

## 第 7 步：同一提示詞 low 對 xhigh（呼叫模型 2 次）＋算輸出成本

1. **標題**：控制變因實驗：同一段 summarize，只換 effort，看 token 和錢差幾倍
2. **目的**：固定提示詞與模型，只把 effort 從 low 換成 xhigh，量真實 output_tokens 的倍數；用 monitor 的 Fable 價目（輸出每百萬 50 美元，與 README 的 10/50 一致）算這兩次的輸出成本差，再用 `analyze()` 把第 6、7 步的 log 合起來出成本報表。強調：這只是本次樣本；effort 是行為訊號不是硬上限；轉接層走 `claude -p --effort`，數字可能和直接打 API 不同。
3. **指令**（`py_run`，程式前面先接共用的 `SUM_PY`）：

   ```python
   import os
   from pathlib import Path
   import anthropic
   import claude_cli_client
   from fable_scanner.monitor import PRICE_PER_M, analyze, print_report
   work = Path("../ch10/interactive").resolve()
   log = work / "calls-compare.jsonl"
   if log.exists():
       log.unlink()
   os.environ["K143_CLI_LOG"] = str(log)
   client = anthropic.Anthropic()                    # 已 install()，拿到的是轉接層
   OUT_PRICE = PRICE_PER_M["claude-fable-5"][1]      # 每百萬輸出 token 的美元
   tok = {}
   for lvl in ("low", "xhigh"):
       try:
           m = client.messages.create(model="claude-fable-5", max_tokens=2048,
                                      output_config={"effort": lvl},
                                      messages=[{"role": "user", "content": SUMMARY}])
           tok[lvl] = m.usage.output_tokens
           print("effort=" + lvl.ljust(6) + " out=" + str(tok[lvl]) + " tok｜回答前 60 字：" + m.content[0].text.strip().replace("\n", " ")[:60])
       except anthropic.APIError as exc:
           print("effort=" + lvl + " ❌ 呼叫失敗：" + str(exc)[:120])
   rows = []
   if len(tok) == 2 and tok["low"]:
       c_low = tok["low"] * OUT_PRICE / 1e6
       c_x = tok["xhigh"] * OUT_PRICE / 1e6
       rows += ["【本次樣本】xhigh / low = " + format(tok["xhigh"] / tok["low"], ".2f") + " 倍",
                "輸出成本：low " + format(c_low, ".6f") + " 美元、xhigh " + format(c_x, ".6f") + " 美元，差 " + format(c_x - c_low, ".6f") + " 美元",
                "放大到一天 1 萬次 summarize：差 " + format((c_x - c_low) * 10000, ".2f") + " 美元"]
   rows += ["claude -p 呼叫次數：" + str(claude_cli_client.calls_made()),
            "注意：effort 不是硬上限，差異可能很小甚至反轉；轉接層用 claude -p --effort 傳遞，結果可能和直接打 API 不同"]
   (work / "effort-compare.txt").write_text("\n".join(rows) + "\n", encoding="utf-8")
   print()
   print("\n".join(rows))
   print()
   print("──── monitor：第 6、7 步合計成本 ────")

   for name in ("calls-run.jsonl", "calls-compare.jsonl"):
   ```
