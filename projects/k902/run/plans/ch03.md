## 第 3 步　練習 1 之二：建立官方 Agent，看模型實際會收到什麼（離線）

**提示（tip）**：還不呼叫模型。先把 Agent 建好，看 _prepare_message_params 組出來的參數，再看轉接層怎麼把工具定義寫進系統提示、怎麼解析 <tool_use> 標記。這是「用提示詞模擬的工具呼叫」，不是 API 原生 tool use；伺服器端工具會被忽略。

**目的**：照練習 1 第 3 點建立 `Agent(name="倉管助理", …)`，讓學習者在花模型額度之前就看清楚：每一輪送出去的參數有哪些、`MessageHistory` 的初始 token 是怎麼估的、`cache_control` 加在哪裡，以及轉接層模擬工具呼叫的具體做法與它的限制（模型不照格式時就只會得到 text）。

print("  " + json.dumps(params["messages"], ensure_ascii=False))
