## 建議（不構成退回）

- **建議｜`ch14.sh:8`**：`K143_CLI_MAX_CALLS=6`，規劃寫的是 4，測試紀錄也用 4 來描述。功能上沒有影響，可以統一成 4，或在規劃裡註明。
- **建議｜`ch14.sh:22-28`（py_run）**：第 7 步會 `import job_packet.packet`，也會 `exec_module` 執行 `mcp_audit.py`。Python 預設可能在 fable5/ 底下產生 `__pycache__`。這是範本共通的行為，前幾章也一樣，所以不算必改。如果想嚴格做到 fable5/ 零寫入，可以在 `sh_run`／`py_run` 加上 `PYTHONDONTWRITEBYTECODE=1`。
- **建議｜`now-ch14.txt` 第 4 步**：本步其實沒用到 tool_choice，工具清單是用 JSON 文字放進 user 訊息。可以加半句，例如「如果你改用真正的 tools 參數……」，讓學習者知道這段補充跟本步程式的關係。
- **建議｜`ch14.sh:63`、`:195`**：同測試紀錄的備註，貪婪的 `\{.*\}` 遇到說明文字裡也有大括號時可能解析失敗。失敗時結果是偏安全的誤擋，之後可以改用 `raw_decode`。
