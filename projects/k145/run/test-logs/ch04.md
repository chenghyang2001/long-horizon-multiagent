## 與規劃的差異（不影響判定，僅供撰寫員與規劃者參考）

1. **第 2 步整齊度表的 sep 從 0.5 改成 0.05**（腳本 `a = es.run_boids(0.05, ...)`／`b = es.run_boids(0.05, ...)`，規劃寫 0.5）。結果仍符合「ali=1 後段 > 0.5、ali=0 < 0.4」的預期；另一個附帶好處是，這兩列可以和第 3 步 sep=0.05 的 ali=0.0、ali=1.0 對帳（0.030/2.02/263、0.805/1.16/686 完全相同），確定性也因此驗證過。建議規劃者把規劃同步改成 0.05。
2. **第 2 步雙胞胎表多了「該 t 的上限」欄**：規劃原本預期「四個估計值都不超過 0.087」，但 0.087 只是 t=150 的上限。t 較小時上限是 ln(447/0.001)/t，所以 t=30 估到 0.2561 在物理上是合理的。撰寫員加上這一欄，並把說明句和第 8 步第 3 點一起改成「約 ln(447/0.001)/t」，等於修正了規劃的錯誤，判為合理。建議規劃者把第 2 步的預期改成「每個估計值 ≤ 該 t 的上限；t=150 時 ≤ 0.087」。
3. **第 5 步「鎖死長路」的門檻從 `x < 0.5` 改成 `x <= 0.1`**。C 版本實測落在 0.45～0.66，比規劃估的「約 0.6～0.92」偏低。如果照原本的門檻，seed 405 的 0.45 會被算成鎖死，但它其實是分流。改門檻後 A、B 的鎖死次數不變（都是 2），C 也正確顯示 0 次。「分流、沒有 1.00、平均明顯低於 A、B」這個重點有呈現出來，所以判為大意相符。建議規劃者把 C 的預期範圍改成「約 0.45～0.7」，鎖死門檻也同步改成 ≤ 0.1。
