## 第 2 步：練習 1 之一：用 ast 把 BROWSER_TOOL_INPUT_SCHEMA 拆成 23 列動作表

**目的**：不 import 官方模組，直接用 ast 從原始碼取出 action 的 enum，看 23 個動作哪些是瀏覽器專屬、哪些在 coordinate／ref 欄位說明裡被點名；順便發現 schema 是「有型別註記的指定式」，找 ast.Assign 會找不到。

**要跑的內嵌 Python**：

```python
import ast, os, sys
sys.path.insert(0, os.getcwd())
from qs_source import read_text

BT = chr(96)
REL = "browser-use-demo/browser_use_demo/tools/browser.py"
BROWSER_ONLY = ["navigate", "read_page", "get_page_text", "find", "form_input", "scroll_to", "execute_js"]
tree = ast.parse(read_text(REL))
schema, schema_line, schema_kind, literal, literal_line = None, None, None, None, None
for node in tree.body:
    name, value = None, None
    if isinstance(node, ast.AnnAssign) and isinstance(node.target, ast.Name):
        name, value = node.target.id, node.value
    elif isinstance(node, ast.Assign) and len(node.targets) == 1 and isinstance(node.targets[0], ast.Name):
        name, value = node.targets[0].id, node.value
    if name == "BROWSER_TOOL_INPUT_SCHEMA":
        schema, schema_line, schema_kind = ast.literal_eval(value), node.lineno, type(node).__name__
    elif name == "Actions" and isinstance(value, ast.Subscript):
        literal, literal_line = [e.value for e in value.slice.elts], node.lineno

print("BROWSER_TOOL_INPUT_SCHEMA：第", schema_line, "行，節點型別", schema_kind, "（有型別註記 dict[str, Any]，所以要找 AnnAssign）")
props = schema["properties"]
actions = props["action"]["enum"]
print("properties 共", len(props), "個：", ", ".join(props))
print("required：", schema["required"])
print()
coord_desc = props["coordinate"]["description"]
ref_desc = props["ref"]["description"]

def named(action, desc):
    return (BT + action + BT) in desc

print("【動作表】是＝符合；－＝不符合（判斷：該欄位 description 裡有沒有用反引號包住的這個 action 名稱）")
print("{:>3} | {:<16} | {:<8} | {:<18} | {:<14}".format("#", "action", "瀏覽器專屬", "coordinate 說明有點名", "ref 說明有點名"))
print("-" * 80)
n_only = n_coord = n_ref = 0
neither = []
for i, a in enumerate(actions, 1):
    o, c, r = a in BROWSER_ONLY, named(a, coord_desc), named(a, ref_desc)
    n_only += o
    n_coord += c
    n_ref += r
    if not c and not r:
        neither.append(a)
    print("{:>3} | {:<16} | {:<8} | {:<18} | {:<14}".format(i, a, "是" if o else "－", "是" if c else "－", "是" if r else "－"))
print("-" * 80)
print("總數：動作 {}｜瀏覽器專屬 {}｜coordinate 點名 {}｜ref 點名 {}".format(len(actions), n_only, n_coord, n_ref))
print()
```

## 第 3 步：練習 1 之二：重寫 scale_coordinates，再看 _click 與 _hover 誰先用 ref

**目的**：自己重寫座標換算的純函式，親眼看到 (728,410) 變 (960,540)、(1456,819) 被壓在 (1919,1079)、(1800,500) 因超過門檻而不變；再從原始碼看出「同時給座標與 ref 時，點擊用座標、hover 用 ref」，以及 ref 點擊其實是「即時問元素中心點再用滑鼠點」。

**要跑的內嵌 Python**：

```python

sys.path.insert(0, os.getcwd())
from qs_source import read_text, grep

D = "browser-use-demo/browser_use_demo/"
CS = D + "tools/coordinate_scaling.py"
BR = D + "tools/browser.py"
print("【常數出處】")
for rel, pat in ((D + "display_constants.py", "^BROWSER_WIDTH = "), (D + "display_constants.py", "^BROWSER_HEIGHT = "),
                 (CS, "CLAUDE_ACTUAL_WIDTH = "), (CS, "CLAUDE_ACTUAL_HEIGHT = "), (CS, "< 0[.]05"),
                 (CS, "[*] 1[.]2"), (CS, "viewport_width - 1"), (CS, "viewport_height - 1")):
    for no, line in grep(rel, pat):
        print("  {}:{}  {}".format(rel.split("/")[-1], no, line.strip()))
print()

CW, CH = 1456, 819

def scale(x, y, vw, vh, apply_threshold=True):
    """照 coordinate_scaling.py 第 106～153 行重寫的純函式。"""
    sx, sy = vw / CW, vh / CH
    if abs(sx - 1.0) < 0.05 and abs(sy - 1.0) < 0.05:
        return x, y, "比例接近 1（差 < 0.05），不換算"
    if apply_threshold and (x > CW * 1.2 or y > CH * 1.2):
        return x, y, "超過 1.2 倍門檻，當成已是實際座標，不換算"
    rx, ry = int(x * sx), int(y * sy)
    nx, ny = min(rx, vw - 1), min(ry, vh - 1)
    note = "換算後壓在視窗上限" if (rx > vw - 1 or ry > vh - 1) else "換算"
    return nx, ny, note

print("倍率：x = 1920/1456 = {:.4f}，y = 1080/819 = {:.4f}（兩者都等於 120/91）".format(1920 / CW, 1080 / CH))
print("門檻：x > {:.1f} 或 y > {:.1f} 就不換算".format(CW * 1.2, CH * 1.2))
print()
cases = [((728, 410), 1920, 1080, "練習題"), ((100, 100), 1920, 1080, "練習題"), ((1456, 819), 1920, 1080, "練習題"),
         ((1800, 500), 1920, 1080, "練習題"), ((1747, 982), 1920, 1080, "補充：門檻內的邊角"), ((728, 410), 1456, 819, "補充：視窗剛好 1456x819")]
print("{:<12} | {:<10} | {:<14} | {:<20} | {}".format("模型座標", "視窗", "實際點下去", "來源", "說明"))
print("-" * 100)
for (x, y), vw, vh, tag in cases:
    nx, ny, note = scale(x, y, vw, vh)
    print("{:<12} | {:<10} | {:<14} | {:<20} | {}".format(str((x, y)), str(vw) + "x" + str(vh), str((nx, ny)), tag, note))
print()

lines = read_text(BR).splitlines()

def body(name):
    start = next(i for i, l in enumerate(lines) if l.startswith("    async def " + name + "("))
    end = next((i for i in range(start + 1, len(lines)) if lines[i].startswith("    async def ") or lines[i].startswith("    def ")), len(lines))
    return start, end

KEYS = ("if coordinate:", "elif coordinate:", "if ref:", "elif ref:", "elif text:")
print("【_click 與 _hover 的判斷順序】")
first = {}
for name in ("_click", "_hover"):
    s, e = body(name)
    order = [(i + 1, lines[i].strip()) for i in range(s, e) if lines[i].strip() in KEYS]
    first[name] = "coordinate" if "coordinate" in order[0][1] else "ref"
    print("  {}（第 {} 行起）：{}".format(name, s + 1, " → ".join("{} 第 {} 行".format(t, n) for n, t in order)))
for no, line in grep(BR, "Prefer ref over coordinate"):
    print("  第 {} 行註解：{}".format(no, line.strip()))
print("  同時給 coordinate 與 ref：left_click 用 {}、hover 用 {} → 兩者不一致，別當成通則".format(first["_click"], first["_hover"]))
print()
print("【ref 點擊其實還是變成座標】")
for no, line in grep(BR, "click_x, click_y = element_info"):
    print("  第 {} 行：{}".format(no, line.strip()))
users = []
for no, _ in grep(BR, "browser_element_script[.]js" + chr(34)):
    owner = [l for l in lines[:no] if l.startswith("    async def ")][-1].strip().split("(")[0].replace("async def ", "")
    users.append("第 {} 行（{}）".format(no, owner))
print("  用 browser_element_script.js 問元素中心點的地方：", "、".join(users))
print("→ ref 不是呼叫 DOM 的 click()，而是當下向頁面問中心點，再用 page.mouse 點下去；它省掉的是「模型從截圖估座標」，所以 ref 分支不經過 _scale_coordinates。")
```

**目的**：讓真模型只看文字版元素樹、只用 ref 完成「填表、送出、讀結果」；每個工具呼叫寫一行 trace，迴圈結束後程式再用舊的 ref_2 點一次，親眼看到換頁後舊 ref 失效的錯誤。

```python
import json, os, sys
from pathlib import Path
sys.path.insert(0, os.getcwd())
os.environ["K902_CLI_MAX_CALLS"] = "2"  # 保險：本行程最多呼叫 claude -p 2 次
import claude_cli_client

Q = chr(34)
MAX_CALLS = 2
out = Path("ch05/interactive")
out.mkdir(parents=True, exist_ok=True)

summary_path = out / "loop_summary.json"
trace_path.unlink(missing_ok=True)

class FakeToolError(Exception):
    pass

class FakePage:
    """假環境：文字版元素樹，不是 DOM、不是 Playwright；ref 只活在這個物件裡。"""
    def __init__(self):
        self.elements = {"ref_1": ("textbox", "Search docs"), "ref_2": ("button", "Search"), "ref_3": ("link", "Pricing")}
        self.query = ""
        self.on_results = False

    def _get(self, ref):
        if ref not in self.elements:
            raise FakeToolError("No element found with reference: " + Q + str(ref) + Q)
        return self.elements[ref]

    def read_page(self):
        return "\n".join("- " + role + " " + Q + name + Q + " [ref=" + ref + "]" for ref, (role, name) in self.elements.items())

    def form_input(self, ref, value):
        role, _ = self._get(ref)
        if role != "textbox":
            raise FakeToolError("form_input only accepts a textbox; " + ref + " is a " + role)
        self.query = str(value)
        return "Filled form field " + ref + " with value: " + self.query

    def left_click(self, ref):
        self._get(ref)
        if ref == "ref_2":
            if not self.query.strip():
                return "Clicked element with ref: ref_2 (search box is empty, page unchanged)"
            self.elements = {"ref_4": ("heading", "3 results for " + self.query), "ref_5": ("link", "Getting started with " + self.query)}
            self.on_results = True
            return "Clicked element with ref: ref_2 (navigated to results page)"
        return "Clicked element with ref: " + ref + " (fake page: nothing happens)"

    def get_page_text(self):
        if self.on_results:
            return "Docs search results\n3 results for " + self.query + "\n1. Getting started with " + self.query + "\n2. " + self.query + " API reference\n3. " + self.query + " pricing FAQ"
        return "Docs home\nSearch docs [" + self.query + "]\nSearch\nPricing"

TOOLS = [
    {"name": "read_page", "description": "讀取目前頁面的元素樹，每行一個元素，結尾附 [ref=ref_N]。換頁後舊 ref 會失效，要重新 read_page。",
     "input_schema": {"type": "object", "properties": {}}},
    {"name": "form_input", "description": "把值填進輸入框（只接受 textbox）。用 read_page 給的 ref 指定元素。",
     "input_schema": {"type": "object", "properties": {"ref": {"type": "string", "description": "read_page 給的 ref_N"}, "value": {"type": "string", "description": "要填入的值"}}, "required": ["ref", "value"]}},
    {"name": "left_click", "description": "點擊元素。用 read_page 給的 ref 指定元素。",
     "input_schema": {"type": "object", "properties": {"ref": {"type": "string", "description": "read_page 給的 ref_N"}}, "required": ["ref"]}},
    {"name": "get_page_text", "description": "取得目前頁面的全部文字，用來讀內容。",
     "input_schema": {"type": "object", "properties": {}}},
]
SYSTEM = "你在操作一個網頁，頁面以文字版元素樹呈現。優先用 read_page 給的 ref 指定元素，不要要求截圖或座標。你可以在同一次回覆裡依序發出多個工具呼叫（每個呼叫各用一段 <tool_use> 標記），它們會照順序執行。不要假裝做了沒做的動作；沒有讀到的內容要老實說。用繁體中文回答。"

page = FakePage()
trace = []

def record(who, call_no, tool, tool_input, fn):
    try:
        result, err = str(fn()), False
    except FakeToolError as exc:
        result, err = str(exc), True
    trace.append({"step": len(trace) + 1, "who": who, "call": call_no, "tool": tool, "input": tool_input,
                  "result": result.replace("\n", " / ")[:80], "is_error": err})
    return result, err

def run_tool(name, tool_input):
    ref = str(tool_input.get("ref", ""))
    if name == "read_page":
        return page.read_page()
    if name == "form_input":
        return page.form_input(ref, tool_input.get("value", ""))
    if name == "left_click":
        return page.left_click(ref)
    if name == "get_page_text":
        return page.get_page_text()
    raise FakeToolError("Unknown tool: " + str(name))

print("假環境：FakePage 是文字版元素樹（Python 物件），不是瀏覽器；模型是真的（claude -p）；工具呼叫是轉接層用提示詞模擬的，不是 API 原生 tool use。")
print()

    texts = [str(b.text) for b in reply.content if b.type == "text"]
    uses = [b for b in reply.content if b.type == "tool_use"]
    details.append({"call": call_no, "stop_reason": reply.stop_reason, "tool_uses": [[u.name, u.input] for u in uses], "text": "\n".join(texts)})
    print("第 {} 次呼叫：stop_reason = {}｜tool_use = {}".format(call_no, reply.stop_reason, [(u.name, u.input) for u in uses] if uses else "無"))
    if texts:
        print("  模型文字：" + " ".join(texts).replace("\n", " ")[:200])
    if not uses:
        final_text = "\n".join(texts)
        if call_no == 1 and call_no < MAX_CALLS:
            retried = True
            print("  這次模型沒有照格式呼叫工具（回覆裡沒有 tool_use），這是提示詞模擬工具呼叫的限制。在上限內重試 1 次，並提醒它用 <tool_use> 標記。")
            messages = [{"role": "user", "content": TASK + "\n\n提醒：請實際用 <tool_use> 標記呼叫工具，不要只用文字描述。"}]
            continue
        if not any(r["who"] == "模型" for r in trace):
            print("  模型這次也沒有照格式呼叫工具（提示詞模擬工具呼叫的限制）；照實記錄拿到的文字，不再呼叫。")
        break
    results = []
    for u in uses:
        res, err = record("模型", call_no, u.name, u.input, lambda u=u: run_tool(u.name, u.input))
        print("  執行 {} {} → {}{}".format(u.name, json.dumps(u.input, ensure_ascii=False), res.replace("\n", " / ")[:120], "（is_error）" if err else ""))
        block = {"type": "tool_result", "tool_use_id": u.id, "content": res}
        if err:
            block["is_error"] = True
        results.append(block)
    messages = messages + [{"role": "assistant", "content": reply.content}, {"role": "user", "content": results}]
    if claude_cli_client.calls_made() >= MAX_CALLS:
        final_text = ""
        print("  已用完 {} 次呼叫上限：這回合的工具已執行並記錄，但不再送回模型拿最後答案。".format(MAX_CALLS))

calls = claude_cli_client.calls_made()
reached = page.on_results
print()
print("【迴圈結束後，程式自己做（不呼叫模型）】")
stale, stale_err = record("程式（迴圈後）", 0, "left_click", {"ref": "ref_2"}, lambda: page.left_click("ref_2"))

    print("  對結果頁 left_click ref_2 →", stale, "｜is_error =", stale_err)
else:

trace_path.write_text("\n".join(json.dumps(r, ensure_ascii=False) for r in trace) + "\n", encoding="utf-8")
model_tools = [r for r in trace if r["who"] == "模型"]
summary = {"calls": calls, "tool_calls": len(model_tools), "query": page.query, "on_results": reached, "retried": retried,
           "error": error, "final_text": final_text, "details": details, "stale_result": stale, "stale_is_error": stale_err}
summary_path.write_text(json.dumps(summary, ensure_ascii=False, indent=2), encoding="utf-8")

print()
print("{:>3} | {:<14} | {:<4} | {:<13} | {:<34} | {:<8} | {}".format("步", "誰發起", "呼叫", "工具", "輸入", "is_error", "結果（前 80 字）"))
print("-" * 150)
for r in trace:
    print("{:>3} | {:<14} | {:<4} | {:<13} | {:<34} | {:<8} | {}".format(r["step"], r["who"], r["call"], r["tool"], json.dumps(r["input"], ensure_ascii=False), str(r["is_error"]), r["result"]))
print()
print("模型呼叫次數：", calls)
print("工具呼叫次數（模型發起）：", len(model_tools), "｜trace 總行數：", len(trace))
print("輸入框最後的值：", page.query or "（空）")
print("是否到達結果頁（模型迴圈結束時）：", reached)
print("是否重試：", retried, "｜錯誤：", error or "無")
print("模型最後答案：", final_text.replace("\n", " ")[:300] if final_text else "（沒有最後答案：呼叫失敗、沒照格式，或第 2 次回覆仍在呼叫工具）")
print()
print("已寫入", trace_path.as_posix(), "與", summary_path.as_posix())
```

**預期看到什麼**：

- 流程上一定會出現：開頭的「假環境：…不是 API 原生 tool use」說明；`=== 工具迴圈（最多 2 次 claude -p…） ===`；trace 第 1 行一定是 `1 | 程式 | 0 | read_page | {} | False | - textbox "Search docs" [ref=ref_1] / - button …`；最後一行 trace 一定是 `程式（迴圈後） | 0 | left_click | {"ref": "ref_2"}`；`模型呼叫次數：` 是 0、1 或 2，**不會超過 2**；最後印 `已寫入 ch05/interactive/trace.jsonl 與 ch05/interactive/loop_summary.json`。結束碼 0。
- 常見的成功情形（每次輸出可能不同，照實記錄）：第 1 次呼叫 `stop_reason = tool_use`，tool_use 依序是 `form_input {"ref": "ref_1", "value": "claude"}`、`left_click {"ref": "ref_2"}`，有時再加 `get_page_text {}`；執行結果 `Filled form field ref_1 with value: claude`、`Clicked element with ref: ref_2 (navigated to results page)`、`Docs search results / 3 results for claude / …`。第 2 次呼叫 `stop_reason = end_turn`、`tool_use = 無`，模型文字說找到 3 筆。迴圈後那一行 `對結果頁 left_click ref_2 → No element found with reference: "ref_2" ｜is_error = True`。`輸入框最後的值： claude`、`是否到達結果頁（模型迴圈結束時）： True`。
- 若模型第 1 次只發 form_input（遵守轉接層「輸出標記後立刻停止」）：第 2 次回覆會再發 left_click，已用完上限，印「已用完 2 次呼叫上限：這回合的工具已執行並記錄，但不再送回模型拿最後答案。」，最後答案顯示「（沒有最後答案：…）」。
- 模型不照格式時：印「這次模型沒有照格式呼叫工具（回覆裡沒有 tool_use），這是提示詞模擬工具呼叫的限制。在上限內重試 1 次…」，第 2 次若仍沒有 tool_use，印「模型這次也沒有照格式呼叫工具…照實記錄拿到的文字，不再呼叫。」；此時 `是否到達結果頁：False`，迴圈後那行印「模型沒有讓頁面到結果頁，所以 ref_2 還有效：Clicked element with ref: ref_2 (search box is empty, page unchanged)…」。
- 呼叫失敗（逾時、CLI 錯誤、超過上限）：印「這次呼叫失敗，原因：APIStatusError：…／APITimeoutError：…（照樣把已有的紀錄存檔，結束碼 0）」，檔案照樣寫出。

**是否呼叫模型**：是，最多 2 次（第 1 次有 tool_use 時第 2 次拿最後答案；第 1 次沒有 tool_use 時第 2 次是重試）。
