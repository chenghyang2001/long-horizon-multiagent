# K902 第 10 章互動演練規劃：autonomous-coding——跨多個 session 的長時間自主寫程式 harness

- 演練類型：導讀＋小模擬（官方 harness 要 Claude Agent SDK、API 金鑰、Puppeteer MCP，還要跑好幾個小時，不能實跑；但 `security.py`、`progress.py` 只用標準庫，可以直接匯入離線實跑）。

- 第 6 步需要本機有 `git` 指令（沒有也不會失敗，只是不產生提交）；單步逾時建議設 300 秒以上。

- 所有程式都已逐字檢查：沒有單引號、錢字號、反引號（需要時用 `chr(34)`、`chr(96)`、`chr(10)`），沒有反斜線接續行，沒有 `input()`，沒有寫死家目錄路徑。

## 第 3 步　練習 1 之二：實跑 bash_security_hook，14 個指令誰放行誰擋下（B 段）

**目的**：把 14 個指令逐一包成 `{"tool_name": "Bash", "tool_input": {"command": cmd}}` 餵給官方 hook，看「允許清單」的判斷：沒列的一律擋、解析不了也擋（失敗時偏向安全）、pkill／chmod／init.sh 列在清單裡還要再過一關。不是 Bash 的工具直接放行。最後補看 init.sh 的例外：不只 `./init.sh`，任何以 `/init.sh` 結尾的路徑也放行。

**要跑的內嵌 Python**：

```python
import asyncio, json, os, sys
sys.path.insert(0, os.getcwd())
import qs_source
sys.path.insert(0, str(qs_source.root() / "autonomous-coding"))
from security import bash_security_hook, extract_commands

Q = chr(34)

def norm(reason):
    # pkill 的理由裡印的是 set，元素順序每次執行可能不同；排序後再印，結果才固定
    if "{" in reason and reason.endswith("}"):
        head, _, rest = reason.partition("{")
        items = sorted(x.strip() for x in rest[:-1].split(","))
        return head + "{" + ", ".join(items) + "}"
    return reason

def layer(reason):
    if reason.startswith("Could not parse"):
        return "解析失敗"
    if "not in the allowed commands list" in reason:
        return "不在允許清單"
    return "額外檢查"

def judge(cmd):
    res = asyncio.run(bash_security_hook({"tool_name": "Bash", "tool_input": {"command": cmd}}))
    if res.get("decision") == "block":
        r = norm(res.get("reason", ""))
        return "擋下", layer(r), r
    return "放行", "-", "-"

CMDS = [
    "ls -la", "npm install && npm run build", "git status || git init", "cat a.txt | grep x",
    "pkill node", "pkill python", "chmod +x init.sh", "chmod 777 init.sh", "./init.sh", "./setup.sh",
    "curl https://example.com", "echo hello; rm -rf /", "python app.py", "echo " + Q + "沒關的引號",
]
print("【B 段】bash_security_hook 的判斷")
print("{:>2} ｜ {:<30} ｜ {:<18} ｜ {:<4} ｜ {:<10} ｜ {}".format("#", "指令", "extract_commands", "判定", "哪一層", "擋下的理由"))
print("-" * 130)
allowed = []
for k, cmd in enumerate(CMDS, 1):
    verdict, where, reason = judge(cmd)
    if verdict == "放行":
        allowed.append(cmd)
    print("{:>2} ｜ {:<30} ｜ {:<18} ｜ {:<4} ｜ {:<10} ｜ {}".format(k, cmd, json.dumps(extract_commands(cmd)), verdict, where, reason))
print()
print("放行 {} 個、擋下 {} 個；放行的是：{}".format(len(allowed), len(CMDS) - len(allowed), "、".join(allowed)))
w = asyncio.run(bash_security_hook({"tool_name": "Write", "tool_input": {"file_path": "a.txt", "content": "hi"}}))
print("tool_name=Write 的回傳：", json.dumps(w), "→ 不是 Bash 的工具直接放行（空 dict 就是放行）")
print()
print("【補充】init.sh 的例外（對照 test_security.py 第 124～131 行）")
for cmd in ("./init.sh arg1 arg2", "/path/to/init.sh", "../dir/init.sh", "bash init.sh"):
    verdict, where, reason = judge(cmd)
    print("  {:<20} → {}　{}".format(cmd, verdict, "" if reason == "-" else reason))
for no, line in qs_source.grep("autonomous-coding/security.py", "script == " + Q + "./init.sh" + Q):
    print("  security.py 第 {} 行：{}".format(no, line.strip()))
print("→ 規則不是「只能 ./init.sh」：路徑以 /init.sh 結尾的也放行；bash init.sh 是被 bash 不在允許清單擋下的。")
```

**預期看到什麼**（全部確定）：

| --- | --- | --- | --- | --- | --- |
| 1 | `ls -la` | `["ls"]` | 放行 | - | - |
| 2 | `npm install && npm run build` | `["npm", "npm"]` | 放行 | - | - |

| 7 | `chmod +x init.sh` | `["chmod"]` | 放行 | - | - |
