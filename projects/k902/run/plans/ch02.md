# K902 第 2 章（ch02）互動演練規劃：financial-data-analyst，讓 Claude 用工具交出圖表資料

- 演練類型：導讀＋小模擬（原專案是 Next.js 網頁應用，要 `npm install` 與瀏覽器，這裡不能實跑）。
- 執行環境：cwd 是 `practice/`，`PYTHONUTF8=1 PYTHONPATH=.`，內嵌 Python 經 heredoc 餵給 `python -`。
- 產出檔（都在 `practice/ch02/interactive/`）：`chart_schema.py`（第 2 步）、`fake_finance.csv`（第 5 步）、`chart_raw.json`（第 6 步）、`chart_report.md`（第 7 步）。
- 呼叫模型：只有第 6 步，問題 1、2 各 1 次；只有「呼叫失敗（逾時、CLI 錯誤）」時整步可重試 1 次，所以最多 3 次。整章最多 3 次（上限 4 次）。模型回了文字但沒有 tool_use 時，照練習 2 的規格記錄「模型沒有畫圖」，不重試。
- 內嵌 Python 都沒有單引號、錢字號、反引號（錢字號用 `chr(36)`、引號用 `chr(34)`、反引號用 `chr(96)`），也沒有反斜線接續行。第 2 步寫進 `chart_schema.py` 的模組原始碼裡完全不含反斜線（換行字元用 `chr(10)`），因為它包在三引號字串裡，`\n` 會被外層字串先轉掉。
- 寫成 `chart_schema.py` 時設 `sys.dont_write_bytecode = True`，練習資料夾不會留下 `__pycache__`。

def validate_chart(d):
    # schema 管得到的：必填欄位、chartType 允許值、config 必填、trend 完整、data 是 dict 清單、chartConfig 有 label
    if not isinstance(d, dict):

            errs.append("缺必填欄位 " + key)
    if "chartType" in d and d.get("chartType") not in CHART_TYPES:
        errs.append("chartType 不在 6 個允許值內：" + str(d.get("chartType")))
    if "config" in d:
        cfg = d.get("config")
        if not isinstance(cfg, dict):
            errs.append("config 不是 dict")

            for key in ("title", "description"):
                if key not in cfg:
                    errs.append("config 缺 " + key)
            if "trend" in cfg:
                tr = cfg.get("trend")
                if not isinstance(tr, dict):
                    errs.append("config.trend 不是 dict")
                else:
                    pct = tr.get("percentage")
                    if isinstance(pct, bool) or not isinstance(pct, (int, float)):
                        errs.append("trend.percentage 缺少或不是數字")
                    if tr.get("direction") not in ("up", "down"):
                        errs.append("trend.direction 缺少或不是 up/down")
    if "data" in d:
        data = d.get("data")
        if not isinstance(data, list) or not all(isinstance(x, dict) for x in data):
            errs.append("data 不是 dict 清單")
    if "chartConfig" in d:
        cc = d.get("chartConfig")
        if not isinstance(cc, dict):
            errs.append("chartConfig 不是 dict")
        else:
            for key, val in cc.items():
                if not isinstance(val, dict) or "label" not in val:
                    errs.append("chartConfig." + str(key) + " 缺 label")
    return errs

    rows = [x for x in d["data"] if isinstance(x, dict)]
    cfg = d.get("config") if isinstance(d.get("config"), dict) else {}
