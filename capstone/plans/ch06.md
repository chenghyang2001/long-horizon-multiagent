## 給腳本撰寫者的共通注意事項

1. 腳本開頭加 `export K143_CLI_MAX_CALLS=4`（第 5 步只要 2 次，留餘裕又擋得住失控迴圈）。
2. 腳本開頭加 `export PYTHONDONTWRITEBYTECODE=1`：第 4、5、7 步會 import `fable5/` 底下的模組，不加會在 `fable5/` 裡產生 `__pycache__/`，違反「不寫入 fable5/」。下面每段 Python 也多寫一行 `sys.dont_write_bytecode = True` 雙重保險。
3. `py_run` 的 heredoc 沒加引號，所以下面的 Python **刻意不含錢字號與反引號**；第 5 步要的三個反引號用 `chr(96) * 3` 組出來，照抄即可。
4. `sh_run` 的指令放在單引號 `P='...'` 裡，所以下面的 shell 指令**一律只用雙引號、不用單引號**（heredoc 用 `<<EOF`，不寫 `<<'EOF'`）。
5. `fable_scanner scan` 有 error 時結束碼是 1、`scope_gate.py` 有 blocking 時也回 1；腳本是 `set -u`（沒有 `set -e`），不會因此中斷，`done_step` 照常印出。

## 第 2 步：畫技能地圖——任務型 vs 常駐型

**目的**：逐一讀出 11 份 SKILL.md 開頭 `---` 區塊的 `name` 與 `description`（description 就是模型判斷「要不要觸發」的依據），再依 README「How they activate」段落分成任務型（自動觸發）與常駐型（明確呼叫或貼進系統提示詞／CLAUDE.md）。分類從 README 原文解析，不靠記憶。產出 `skill-map.md`。

**指令（py_run）**：

```python
sys.dont_write_bytecode = True
import re
from pathlib import Path

work = Path("../ch06/interactive").resolve()
work.mkdir(parents=True, exist_ok=True)

readme = Path("skills/README.md").read_text(encoding="utf-8")
section = readme.split("## How they activate", 1)[1].strip()
print("──── README：How they activate 原文 ────")
print(section)
print()
task_shaped = re.findall(r"[a-z]+(?:-[a-z]+)+", section.split("are task-shaped", 1)[0])

# 對應前面章節的書附模組（只列真的存在的目錄）
related = {
    "lesson-memory": "memory/（第 3 章）",
    "mythos-scope-gate": "mythos_scope/",
    "refusal-aware-calling": "fable_scanner/ 的 MG-01 規則",
    "scope-fence": "projects/04_refactor_legacy/",
    "verifier-subagent": "agentic_soc/（第 2 章）",
}

def front_matter(text):
    """取出開頭 --- 區塊裡的 name 與 description。"""
    head = text.split("---", 2)[1] if text.startswith("---") else ""
    fields = {}
    for line in head.splitlines():
        if ":" in line:
            key, value = line.split(":", 1)
            fields[key.strip()] = value.strip()
    return fields

rows = ["| # | 技能 | 類型 | 建議放哪裡 | 相關書附模組 | description 前 70 字 |",
        "|---|------|------|------------|--------------|----------------------|"]
counts = {"任務型": 0, "常駐型": 0}
for i, skill_md in enumerate(sorted(Path("skills").glob("*/SKILL.md")), 1):
    meta = front_matter(skill_md.read_text(encoding="utf-8"))
    name = meta.get("name", skill_md.parent.name)
    kind = "任務型" if name in task_shaped else "常駐型"
    counts[kind] += 1
    where = "自動觸發" if kind == "任務型" else "明確呼叫／貼進 CLAUDE.md"
    desc = meta.get("description", "（缺 description）")[:70]
    rows.append("| " + " | ".join([str(i), name, kind, where, related.get(name, "－"), desc]) + " |")

table = "\n".join(rows)
(work / "skill-map.md").write_text("# 第 6 章技能地圖\n\n" + table + "\n", encoding="utf-8")
print(table)
print()
print("任務型 " + str(counts["任務型"]) + " 個：" + "、".join(task_shaped))
print("常駐型 " + str(counts["常駐型"]) + " 個")
print("已寫入 " + str(work / "skill-map.md"))
```

**預期看到**：

- 先印 README 英文段落（含 `effort-router`, `verifier-subagent`, and `lesson-memory` are task-shaped…，以及 `autonomy-contract` is written for exactly that case）。
- 一張 11 列的 Markdown 表格，依字母排序（第 1 列 act-on-sufficiency、第 11 列 verifier-subagent），每列 description 都有內容（沒有「缺 description」），開頭多為 `Stop Claude Fable 5 …`、`Bind every progress claim …` 這類句子，可在原檔第 3 行找到。
- `任務型 3 個：effort-router、verifier-subagent、lesson-memory`、`常駐型 8 個`（3＋8＝11）。
- `practice/ch06/interactive/skill-map.md` 被建立。

**是否呼叫模型**：否

## 第 4 步：先自己找證據——parse_log 會默默少算

## 第 5 步：A/B 真實對照——掛上範圍圍欄＋證據綁定進度（呼叫模型 2 次）

**目的**：同一個「只是在問問題」的請求送兩次：A 版 system 只有「你是資深工程師」；B 版再加上 scope-fence 與 evidence-bound-progress 兩份 SKILL.md 本文（去掉開頭 `---` 區塊）。比較模型會不會直接丟出改好的整份程式、附送沒人要的備份／README／工單、結論有沒有指向 probe.txt 的證據。讓學習者親眼看到「常駐型技能要放進系統提示詞」的效果。

**指令（py_run）**：

```python
sys.dont_write_bytecode = True
import os
from pathlib import Path
import anthropic

work = Path("../ch06/interactive").resolve()
probe = work / "probe.txt"
log = work / "calls.jsonl"

def skill_body(name):
    text = Path("skills", name, "SKILL.md").read_text(encoding="utf-8")
    return text.split("---", 2)[2].strip() if text.startswith("---") else text

def metrics(text):
    low = text.lower()
    return [str(len(text)),
            str(text.count(fence) // 2),
            "有" if ("def parse_line" in text or "def parse_log" in text) else "－",
            "有" if any(k in low for k in ["readme", "備份", "backup", "工單", "ticket"]) else "－",
            "有" if ("probe" in low or "第 3 行" in text or "第 5 行" in text or "第 7 行" in text) else "－"]

fence = chr(96) * 3
if not probe.exists():
    print("找不到 " + str(probe) + "，先跑第 4 步")
else:
    if log.exists():
        log.unlink()                      # 舊 log 會讓呼叫次數算錯
    os.environ["K143_CLI_LOG"] = str(log)
    source = Path("projects/04_refactor_legacy/sample_target.py").read_text(encoding="utf-8")
    question = ("我們的 SIEM 解析器 parse_log 好像有時候少算幾行，怎麼回事？\n\n"
                "sample_target.py 全文：\n" + fence + "python\n" + source + fence + "\n\n"
                "probe.txt：\n" + fence + "\n" + probe.read_text(encoding="utf-8") + fence)
    base = "你是資深工程師。"
    systems = {"A": base,
               "B": base + "\n\n" + skill_body("scope-fence") + "\n\n" + skill_body("evidence-bound-progress")}
    client = anthropic.Anthropic()        # 已被轉接層換成 claude -p
    answers = {}
    for tag, system in systems.items():
        print("送出 " + tag + " 版（system " + str(len(system)) + " 字）…")
        try:
            resp = client.messages.create(model="claude-fable-5", max_tokens=2000, system=system,
                                          messages=[{"role": "user", "content": question}])
            answers[tag] = resp.content[0].text
        except anthropic.APIError as exc:
            answers[tag] = "（呼叫失敗：" + str(exc) + "）"
        (work / ("answer-" + tag + ".md")).write_text(answers[tag] + "\n", encoding="utf-8")
    print()
    print("指標｜A 版｜B 版")
    names = ["回答字數", "程式碼區塊數", "重寫了 parse 函式", "提到備份/README/工單", "引用 probe 證據"]
    for n, a, b in zip(names, metrics(answers["A"]), metrics(answers["B"])):
        print(n + "｜" + a + "｜" + b)
    print()
    print("全文：ch06/interactive/answer-A.md、answer-B.md")
    print("本步呼叫次數：" + str(claude_cli_client.calls_made()))
```

**預期看到**：

- `送出 A 版（system 8 字）…`、`送出 B 版（system 約 2,500～3,000 字）…`，兩次共約 40～180 秒。
- 一張 5 列對照表（回答字數／程式碼區塊數／重寫了 parse 函式／提到備份 README 工單／引用 probe 證據），A、B 欄都有值。
- 兩版都應指出根因：`PATTERN` 的 `severity=(\d)` 只吃一位數、`user=` 必填、比對失敗 `return None` 被默默跳過。
- 傾向（不保證，照實看）：B 版「重寫了 parse 函式」較可能是「－」、程式碼區塊較少、「提到備份/README/工單」為「－」、「引用 probe 證據」為「有」；A 版較可能直接附一份改好的 `parse_line`。兩版差不多也是有效結果（可能原因：Fable 5 本身已偏向先診斷，或問題語氣已很明確），測試者照實記錄即可。
- `本步呼叫次數：2`；`ch06/interactive/` 多出 `answer-A.md`、`answer-B.md`、`calls.jsonl`（2 行）。
- 呼叫失敗時對應欄位寫「（呼叫失敗：…）」，不會整支崩潰；轉接層會忽略 `max_tokens`。

**是否呼叫模型**：是（2 次，`claude-fable-5` 經 `claude_cli_client` 轉接層走 `claude -p`）

## 第 7 步：親手造三份會被擋的工作包

**目的**：把閘門的每一類錯誤親手觸發一次：Mythos 工作包夾帶禁止動作、Mythos 工作包缺授權範疇／私有證據庫／修補負責人、Fable 工作包沒有拒答紀錄也沒有備援。看清楚哪些是 error（擋下、結束碼 1），哪些只是 warn（放行但提醒、結束碼 0）。欄位名稱取自第 6 步看到的程式碼；壞工作包從書附範例複製後改，寫在 `ch06/interactive/`。

**指令（py_run）**：

```python
sys.dont_write_bytecode = True
import contextlib, copy, io, json
from pathlib import Path
import mythos_scope.scope_gate as gate

work = Path("../ch06/interactive").resolve()
work.mkdir(parents=True, exist_ok=True)
mythos = json.loads(Path("mythos_scope/sample_mythos_scope.json").read_text(encoding="utf-8"))
fable = json.loads(Path("mythos_scope/sample_fable_scope.json").read_text(encoding="utf-8"))

bad_forbidden = copy.deepcopy(mythos)
bad_forbidden["allowed_actions"] += ["public_poc", "exfiltration"]

bad_missing = copy.deepcopy(mythos)
for field in ["authorization_id", "glasswing_scope_id", "evidence_store", "human_patch_owner"]:
    del bad_missing[field]

fable_no_telemetry = copy.deepcopy(fable)
del fable_no_telemetry["refusal_logging"]
del fable_no_telemetry["fallbacks"]

packets = {"bad-forbidden.json": bad_forbidden,
           "bad-missing.json": bad_missing,
           "fable-no-telemetry.json": fable_no_telemetry}
report = []
for name, packet in packets.items():
    path = work / name
    path.write_text(json.dumps(packet, ensure_ascii=False, indent=2), encoding="utf-8")
    buf = io.StringIO()
    with contextlib.redirect_stdout(buf):
        code = gate.main(str(path))
    report.append("════ " + name + " ════\n" + buf.getvalue().rstrip() + "\n結束碼：" + str(code)
                  + ("（擋下）" if code else "（放行，但有提醒）"))
text = "\n\n".join(report)
print(text)
(work / "gate-results.txt").write_text(text + "\n", encoding="utf-8")
print()
print("已寫入 " + str(work / "gate-results.txt"))
print("fable5/mythos_scope 裡的 json 數量（應仍為 2）：" + str(len(list(Path("mythos_scope").glob("*.json")))))
```

**預期看到**：

- `bad-forbidden.json`：1 筆 `error  allowed_actions`，訊息 `Forbidden action(s) cannot be approved here: exfiltration, public_poc`；`1 finding(s), 1 blocking`；`結束碼：1（擋下）`。
- `bad-missing.json`：4 筆 error，依序 `authorization_id`、`glasswing_scope_id`、`evidence_store`、`human_patch_owner`，訊息皆為 `Mythos workloads require this field before the run starts.`；`4 finding(s), 4 blocking`；`結束碼：1（擋下）`。
- `fable-no-telemetry.json`：2 筆 `warn`（`refusal_logging`、`fallbacks`）；`2 finding(s), 0 blocking`；`結束碼：0（放行，但有提醒）`。
- `已寫入 …ch06\interactive\gate-results.txt`，以及 `fable5/mythos_scope 裡的 json 數量（應仍為 2）：2`。

**是否呼叫模型**：否
